# PIE-Block 1.10.0

1.10.0 是 1.9.0 之后的**无线通信专项版本**：车体固件加入断链保护与 NRF 收包时序整改，生成代码增加断链安全状态；无线链路参数由 1 Mbps 调整为 **250 kbps**，遥控器（手柄）配套固件同步改为 **250 kbps / 25 Hz** 并更新界面与排障页。存档格式保持 **23**，1.9.0 的工程打开即可直接使用。

> ⚠️ **本版车体固件与手柄固件必须成对升级。** 只升级一端（车体或手柄）会完全失去控制；断链保护也会在单端升级后表现为“车体不动”。

## 下载

| 文件 | 说明 |
| --- | --- |
| `PIEBlock-1.10.0-windows-setup.exe` | Windows 安装包，双击按向导安装 |
| `PIEBlock-1.10.0-windows-portable.exe` | Windows 单文件便携版，免安装，首次启动自解压约 1–2 秒 |
| `PIEBlock-1.10.0-windows-x64-release.zip` | Windows 免安装版，解压后运行 `PIE-Block.exe` |
| `PIEBlock-1.10.0-linux-x64.tar.gz` | Linux 免安装版，解压后运行 `pieblock_app` |

产物文件名与标签一致：`PIEBlock-1.10.0-*`（构建号 17）。Windows 与 Linux 都内置离线 SDCC C251 工具链与 STC32G 固件模板，**无需另外安装编译器**即可编译并烧录步兵、工程、调试与音乐四类工程；Linux 首次烧录前仍需授权 hidraw 设备，可在应用内「烧录」页一键安装。

**手柄固件不随本安装包发布**：遥控器固件与升级工具在独立仓库 <https://gitee.com/wpie/rm_xbox>，使用 `tools/rc_tool.py` 升级（只写应用区，保留 `0x08010000` 通道配置页）。

**本次 Release 不附带 Android 安装包**：仓库未配置发布签名 Secrets，`v*` 标签的 Android 流水线会被签名门禁拦截。Android 版仍只支持配置、编辑与预览，不能在本机编译固件。

## 主要变化（自 1.9.0 起）

### 无线链路参数：1 Mbps → 250 kbps（破坏性变更）

- 车体运行时改为 `RF_SETUP=0x27`（250 kbps）、`SETUP_RETR=0x15`（自动重发 1 次、ARD 1500 µs），初始化后回读 `RF_CH` / `RF_SETUP` / `SETUP_RETR` 校验；
- 遥控器端同步 250 kbps，发送周期 25 Hz；
- 250 kbps 的接收灵敏度更高、距离更稳，但 **1.9.0 的旧手柄固件（1 Mbps）与本版车体固件互不通信**，反之亦然；
- 十路 IO 遥测帧格式不变（帧头 1 + 10 × int16 小端 + 校验 1，共 22 字节），旧存档/旧工程无需迁移。

### 车体固件：断链保护与 NRF 收包整改

- **断链保护**：超过 150 ms 没有有效控制帧即清空控制量并置 `KEY_RCDISCONNECTED`，避免断链后机器人按最后一帧持续动作；
- **收包时序**：修复 NRF 轮询丢包与断联后无法重连；按 `RX_PNO` / `FIFO_STATUS` 正确读空 RX FIFO，不再把空 FIFO 的未定义数据当作控制包；
- **遥测发送**：改为有界等待 `TX_DS/MAX_RT` 后立即切回 RX（旧实现固定延时 3 ms，重发未结束时车体会停在 TX、收不到控制帧）；
- 新增链路统计 `RC_LinkStats_t`（valid / header_error / checksum_error / rx_full / max_rt / tx_ds / timeouts）与 `RcLinkClockInit/Service/IsLost`；时基使用 Timer0 轮询，不启用定时器中断。

### 生成代码

- 生成的车体主循环增加**断链安全状态**与阻塞收包助手：断链时输出安全值，收包按超时阻塞，避免无帧时空转；
- SDCC 黄金基线随运行时更新重刷。

### 遥控器（手柄）配套固件（`wpie/rm_xbox`）

- 250 kbps / 25 Hz 链路；主屏十路 IO 状态两列五行显示；顶栏成功率只统计上行 ACK；
- 无线故障分级页（模块丢失 / 无载波 / 有载波解不出包 / 链路中断），故障页也可长按 MODE 进入管理员菜单；
- 管理员「信号」页：从机旁听，被动接收统计 + 三位滚轮选频 + 串口 CSV；
- 修复：25 Hz 发送周期下摇杆校准误判未归中、ADC 校准失败导致上电黑屏、16px 汉字顶部裁字、长按进度环遮罩、成功率 100% 显示成 `:0%`；
- 工具：`tools/rc_tool.py`（固件升级 + 通道号设置，支持 128 KiB 兼容片）、`tools/swd_link_capture.py`、`tools/probe_check.py`。

### SDCC 固件工程与调试工具（开发者）

- 新增车体串口调试台工程 `stc32g_sdcc/projects/DBG_CONSOLE`：启动复位诊断（按手册解码 `RSTFLAG`）、nRF 寄存器回读、运行快照与事件、`s/r/d/l/b/m/e/z/p/w/t` 命令、保留 XRAM 面包屑（`# LAST stage=…`）定位跑飞；
- 定位并修复 SDCC mcs251 **ISR 不保存 DPXL** 导致的 ROMOVF 复位循环（表现为初始化提示音反复响）：ISR 入口手工 `push/pop dpxl`，nRF CE/CSN 改位寻址直写；排查记录见 `docs/pitfall/`；
- USB-CDC 调试桥：新增 UART3 printf 调试口、修复 IE2 读改写清掉 EUSB 导致 USB 中断不触发、USB 初始化前先断开避免冷启动 HID 枚举残留、支持发送 `@STCISP#` 软复位回系统 ISP；
- UART2 调试测试固件改用中断接收环形缓冲，并增加 UART3 中断诊断输出。

## 升级提示

- **1.9.0 → 1.10.0**：存档格式不变（23），打开旧工程直接可用；
- **必须配对升级**，推荐顺序：
  1. 用 `rc_tool.py` 把手柄升级到本版配套固件（保留通道配置页，升级后核对屏幕界面与 BUILD 时间）；
  2. 用本版 PIE-Block 重新生成并烧录车体固件（旧版生成固件不要继续沿用，运行时参数已变）；
  3. 台架确认：手柄能控制车体、主屏十路 IO 正常刷新、断链后车体停止动作；
  4. 同一台车/同一支手柄始终使用同一版本，避免混用；
- 断链保护会使“断链后机器人停止动作”，这是预期行为；需要持续动作时必须先恢复链路；
- 发版前建议用一对确认可靠的 nRF24L01+ 模块做台架验证，再全队发放。

## 已知限制

- 250 kbps 链路、十路 IO 回传与断链保护均未在仓库内做真机自动验证，首次使用请台架确认；
- 遥控器固件不随本安装包发布，需要从 `wpie/rm_xbox` 构建并升级；
- Android 安装包因发布签名 Secrets 未配置，仍不随 Release 提供；
- TUI 是独立发布线，不在本 Release 的安装包内。
