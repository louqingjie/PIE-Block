# PIE-Block 1.8.1

1.8.1 是 1.8.0 之后的稳定修订版，在灵敏度功能基础上补入工程舵机角度校验修复：步兵与工程新增**底盘转向灵敏度**和**云台俯仰 / 偏航灵敏度**，修复工程舵机动作角度被固定 ±90° 误判为越界的问题，存档格式由 **22 升到 23**。1.8.0 生成的工程仍可直接打开并按格式 23 写回；设置保持 100%、舵机角度未触及旧限制时生成代码与 1.8.0 逐字节一致。

## 下载

| 文件 | 说明 |
| --- | --- |
| `PIEBlock-1.8.1-windows-setup.exe` | Windows 安装包，双击按向导安装 |
| `PIEBlock-1.8.1-windows-portable.exe` | Windows 单文件便携版，免安装，首次启动自解压约 1–2 秒 |
| `PIEBlock-1.8.1-windows-x64-release.zip` | Windows 免安装版，解压后运行 `PIE-Block.exe` |
| `PIEBlock-1.8.1-linux-x64.tar.gz` | Linux 免安装版，解压后运行 `pieblock_app` |

产物文件名与标签一致：`PIEBlock-1.8.1-*`（构建号 15）。Windows 与 Linux 都内置离线 SDCC C251 工具链与 STC32G 固件模板，**无需另外安装编译器**即可编译并烧录步兵、工程、调试与音乐四类工程；Linux 首次烧录前仍需授权 hidraw 设备，可在应用内“烧录”页一键安装。

**本次 Release 不附带 Android 安装包**：仓库未配置发布签名 Secrets，`v*` 标签的 Android 流水线会被签名门禁拦截，不会用 debug 签名冒充正式版。Android 版仍只支持配置、编辑与预览，不能在本机编译固件。

## 主要变化（自 1.8.0 起）

### 底盘转向灵敏度

- 步兵与工程的遥控器 / 底盘页新增“转向灵敏度”滑块，整数范围 **10–200%**，缺省 **100%**。
- 只缩放右摇杆水平方向与左右方向键产生的转向量，不影响前后移动、冲刺和单轮方向配置；`100%` 时生成的 `CalculateChassis` 与 1.8.0 完全一致。
- 高于 150% 时给出“轮速可能超出 duty 上限”警告，但不阻止生成；超出 10–200 时作为错误阻止生成。

### 云台灵敏度

- 步兵的机械 / 云台页分别为 Yaw 与 Pitch 新增灵敏度滑块，整数范围同为 **10–200%**，缺省 **100%**。
- 舵机轴按灵敏度比例缩放每主循环的摇杆增量；电机轴按灵敏度比例缩放满杆占空比。`100%` 时生成代码与 1.8.0 逐字节一致。
- 高于 150% 时提示“角度变化可能过快”，不阻止生成；超出 10–200 时作为错误阻止生成。
- 审查页摘要同步显示底盘与云台三处灵敏度，便于在生成固件前核对。

### 修复：工程舵机角度按中位两侧行程放宽

- 工程项目的舵机动作角度不再统一限制在 −90°–+90°，改为按该引脚 PWM 中位偏移与限幅推导出的两侧电气行程校验；直接模式动作行与动作表档位都适用。
- 中位偏移会让一侧行程超过 90°：中位 60°、顺时针限幅 120° 时可以填写 −120°（绝对 −60°）；超出推导出的该侧行程仍作为错误阻止生成。
- 生成代码仍按绝对角度换算 duty。此前被旧范围误判为越界、只能改成近似值的配置，现在可按实际行程填写并重新生成；本次修复不新增存档字段。

### 存档格式 23 与兼容性

- 新增可选的 `chassis.turn_sensitivity` 与步兵 `yaw_sensitivity` / `pitch_sensitivity`；缺省 `100` 的旧存档读入后行为与 1.8.0 一致。
- 内置模板、教材示例工程已按格式 23 重新保存；`packages/pieblock_core/test/fixtures/` 增加格式 22 的工程与步兵回归样本，覆盖 22 → 23 升版。
- 项目文件格式文档同步说明三处字段的范围、缺省值、代码生成影响与 150% 警告阈值。

## 升级提示

- **可读入格式 17–22 的旧存档**，打开后按格式 23 写回；格式 16 及更早版本仍需重建配置。1.8.0 及更早版本无法打开格式 23 文件，会明确提示升级，不会静默丢字段。
- 三处灵敏度均为 `100%` 时无需改动已烧录固件；只要任一处不是 `100%`，生成代码就会变化，必须重新生成并烧录固件。
- 此前因固定 ±90° 校验而改成近似舵机角度的工程，可在本版按实际中位与限幅重填真实角度；修改后同样需要重新生成并烧录固件。
- 高于 150% 的组合请先在低速、空旷场地验证转向与云台速度，避免轮速超过 duty 上限或云台动作过快。
- 便携版首次启动仍需 1–2 秒解压；换版本会新建解压目录，旧目录不会自动清理。应用设置仍保存在系统应用数据目录。

## 已知限制

- Windows 安装包、便携版与免安装 zip **均未做代码签名**，SmartScreen 可能提示“未知发布者”，选择“仍要运行”即可；Linux 只提供 tar.gz，未做发行版原生包与桌面集成。
- **本次不提供 Android 安装包**（发布签名 Secrets 未配置）；Android 版不能在本机构建固件。
- Web 版是只读演示：可以配置项目、查看并导出生成的 C 代码，**不能编译或烧录**。
- 使用 Keil 编译需要本机已安装并授权 Keil C251（仅 Windows）；使用内置 SDCC 则无此要求。
- 教材示例工程按当前格式与截图生成，但示例控制律不承诺适配具体车体：引脚分配、电机方向、舵机中位都要按实车重新核对后再烧录。
