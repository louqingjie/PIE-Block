# PIE-Block 1.7.0

本次发布把工程项目从“固定坦克底盘 + 简单映射”扩展为可配置底盘、变量/表达式与摩擦轮安全控制的完整工程配置器，项目文件升级到 **格式 17**；同时补充云台与工程舵机的逆时针/顺时针限幅、动作行拖动排序与复制、调试测试项复制，以及底部可折叠的问题面板。随书教材与六份示例工程也已完稿入库。

## 下载

| 文件 | 说明 |
| --- | --- |
| `PIEBlock-1.7.0-windows-setup.exe` | Windows 安装包，双击按向导安装 |
| `PIEBlock-1.7.0-windows-portable.exe` | Windows 单文件便携版，免安装，首次启动自解压约 1–2 秒 |
| `PIEBlock-1.7.0-windows-x64-release.zip` | Windows 免安装版，解压后运行 `PIE-Block.exe` |
| `PIEBlock-1.7.0-linux-x64.tar.gz` | Linux 免安装版，解压后运行 `pieblock_app` |

Windows 与 Linux 都内置离线 SDCC C251 工具链与 STC32G 固件模板，**无需另外安装编译器**即可编译并烧录步兵、工程、调试与音乐四类工程。Linux 首次烧录前仍需授权 hidraw 设备，可在应用内「烧录」页一键安装。

Release 同时附带稳定命名副本 `PIEBlock-windows-setup.exe` 与 `PIEBlock-linux-x64.tar.gz`，供官网直链使用（`/releases/latest/download/...`，不随版本号变化）。

**本次 Release 仍不附带 Android 安装包**：打 `v*` 标签时 Android 流水线会强制校验发布签名 Secrets，仓库没有配置，CI 会拦截标签构建；Android 的 Release 构建也仍未启用本地编译流水线，只能配置、编辑与预览，不能编译固件。

## 主要变化

**工程项目：格式 17 与高级配置**

- 预制四轮底盘改为可选：关闭后释放四路底盘引脚，可搭配麦克纳姆轮、全向轮或由动作行自行接管四轮；不保留底盘的模式会在 `PrepareMode()` 中把底盘槽归零，避免切模式后残留速度。
- 动作行扩展为“输入 → 输出 → 方向 → 控制方式 → 参数”的完整映射：输入支持遥控器按键/摇杆或“未指定”，输出支持引脚、整数变量、有理数变量；表达式行可直接把计算结果写到引脚或变量。
- 新增受限表达式：支持字面量、变量、`LX/LY/RX/RY`、按键别名、四则运算、比较、逻辑、三元表达式及 `abs/min/max/sign/sqrt/atan2`、`PI/E`；禁止分号、花括号、赋值、下标等自由 C 语法。变量按模式自动区分为局部变量与全局变量，类型必须一致。
- 新增表达式编译检查与试算：桌面端可用内置 SDCC 对生成代码做完整编译检查并回填错误，所有平台都可打开「试算表达式」，用滑杆输入查看每行结果与中间变量。
- 新增工程摩擦轮控制：P64/P66 角色为摩擦轮且 PWMA 为 50 Hz 时可用启停、油门单次、油门持续、摇杆油门四种模式；共享油门百分比与每脚满油上限，固件走 500 启动占空比、1000 ms 电调激活、逐周期 ±1 爬升的安全栈，旧控制方式仍可用但会提示不受斜坡保护。
- 工程项目格式升级到 **17**；四份模板工程已按新格式重存，随书新格式示例工程同步入库。

**舵机限幅：逆时针/顺时针统一**

- 步兵云台舵机行程放开到电气全程 ±90°，并按归中偏移计算两侧可用行程；限幅改为按「逆时针限幅」「顺时针限幅」的行程大小输入，逆时针不超过 `90° − 归中偏移`、顺时针不超过 `90° + 归中偏移`。
- 工程 PWM 页的舵机限幅使用同一套两侧行程语义和符号约定；原先的“左/右限位”带符号端点输入改为“逆时针/顺时针限幅”，并补上归中偏移约束。
- 限幅超出该侧电气余量现在会直接报错并阻止生成，不再被生成器静默截断；依赖旧配置的工程需要重新核对两侧限幅。

**向导交互**

- 工程动作映射页支持拖动排序：左侧手柄可调整动作执行顺序，列表独立滚动并保留问题面板跳转。
- 工程动作行新增复制键：在源动作下方插入一条字段完全相同的动作，副本使用新的稳定 ID，编号与执行顺序自动顺延。
- 调试测试项新增复制键：允许同一引脚配置多条测试，复制项插在源项下方；测试项新增可选稳定 `id`，复制后可分别编辑、启停和拖动。
- 步骤错误/警告面板从页头移到右下角操作区：默认折叠为「X 项错误 · Y 项提醒」摘要，展开后浮层显示问题列表；宽屏在“上一步/下一步”左侧，窄屏在操作组上方。背景改为中性表面色，严重度只通过图标和文字颜色表达，仅提醒时不再整块红色。
- 调试提示音在启用超过 10 项时会说明第 11 项起音型复用，界面序号仍递增。

**固件与生成修复**

- 修正阻塞拨弹脉冲未先补发方向帧的问题：反向拨弹配置下扳机与反向键曾经同向，现在会先发送方向帧再发脉冲。
- 步兵舵机不再允许选择固定 10000 Hz 的 P74–P77，避免电机 PWM 组无法驱动舵机。
- 补齐工程/步兵生成代码的排列组合测试与执行级核对，覆盖变量、表达式、摩擦轮、限幅和模式切换。

**教材与文档**

- 教材第 1–10 章与附录完稿：新增前言、工程项目高级配置、调试工程、代码生成与静态检查等章节，配图与示例工程逐项对照。
- 六份随书示例工程（步兵、工程三份、调试、音乐）已入库，供导入、截图生成与 CI 校验共用。

## 升级提示

- **项目文件格式从 16 升级到 17，1.6.0 及更早的 `.pieproj` 不兼容**：应用会拒绝打开，且不会自动迁移。请先用旧版本打开并导出参考配置，或按《Flutter 项目文件格式》手工重建。升级前务必备份项目目录。
- **必须重新编译并烧录**：格式 17 的工程配置、云台舵机行程/限幅、拨弹方向帧和工程摩擦轮生成逻辑都发生了变化，旧固件不能继续使用新配置。安装版升级后需要用新版本重新生成并烧录。
- 舵机限幅校验更严格：原先超出该侧电气余量但被生成器截断的配置，升级后会变成错误，需要调整到 `0–(90 − 归中偏移)` / `0–(90 + 归中偏移)` 内。
- 动作行与调试测试项复制会写入新的稳定 ID；旧文件不写该字段，重存不会产生无用 diff。
- 便携版首次启动仍需 1–2 秒解压；换版本会新建解压目录，旧目录不会自动清理。应用设置仍保存在系统应用数据目录。

## 已知限制

- Windows 安装包、便携版与免安装 zip **均未做代码签名**，SmartScreen 可能提示「未知发布者」，选择「仍要运行」即可；Linux 侧只提供 tar.gz，未做发行版原生包与桌面集成。
- **本次没有 Android 安装包**（发布签名 Secrets 未配置，打 `v*` 标签会被 CI 拦截）；Android 只能配置、编辑与预览，不能编译固件。
- Web 版是只读演示：可以配置项目、查看并导出生成的 C 代码，**不能编译或烧录**。
- 使用 Keil 编译需要本机已安装并授权 Keil C251（仅 Windows）；使用内置 SDCC 则无此要求。
- 调试序列启用超过 10 项时提示音会复用第 6–10 项音型，请以界面序号为准；同轴多舵机的限幅按各侧最紧值取交集。
- 教材示例工程按当前格式与截图生成，但示例控制律不承诺适配具体车体：引脚分配、电机方向、舵机中位都要按实车重新核对后再烧录。
