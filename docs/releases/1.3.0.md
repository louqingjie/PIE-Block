# PIE-Block 1.3.0

修复 Linux 大固件烧到一半失联的根因（实机验证），Linux 支持在应用内一键安装 udev 规则；调试提示音改为「步序旋律 + 卡农完成音」并提供试听面板；摩擦轮从静止启动新增 1000ms 电调激活阶段；首次提供 Android 安装包。

## 下载

| 文件 | 说明 |
| --- | --- |
| `PIEBlock-1.3.0-windows-setup.exe` | Windows 安装包，双击按向导安装 |
| `PIEBlock-1.3.0-windows-x64-release.zip` | Windows 免安装版，解压后运行 `PIE-Block.exe` |
| `PIEBlock-1.3.0-linux-x64.tar.gz` | Linux 免安装版，解压后运行 `pieblock_app` |
| `PIEBlock-1.3.0-android.apk` / `.aab` | Android 通用安装包与上架用 AAB（见下方「Android」与「已知限制」） |

Windows 与 Linux 都内置离线 SDCC C251 工具链与 STC32G 固件模板，**无需另外安装编译器**即可编译并烧录步兵、工程、调试与音乐四类工程。Linux 首次烧录前仍需授权 hidraw 设备，本版本可直接在应用内一键安装（见下）。

Android 另附稳定命名副本 `PIEBlock-android.apk` / `PIEBlock-android.aab`，供官网直链使用。

## 主要变化

**Linux 烧录：修复大固件写到约 130 块后失联（根因，实机验证）**

- 现象：写入较大的固件时，约到第 129～130 块（0x4080）设备失联并退出 ISP，重发与重开会话都无效，只能断电重新上电；小固件不易触发。
- 根因：Linux 原生传输层沿用了「hidraw 会替主机剥掉 report ID 槽」的错误假设，只写 64 字节。Linux 的 hidraw 并不剥离，设备固件按 HID 约定再剥一次首字节，导致整帧错位。Windows 走 hidapi 语义（写 65 字节），因此一直没暴露；只有 Linux 踩中。
- 修复：原生层改为原样写 65/65/64 字节（不再剥 `data[0]`）；对设备忙（`EBUSY`/`EAGAIN`/`EINTR`/`ETIMEDOUT`）做与 Windows 等价的**有界退让重试**（2000ms 窗口、1ms 间隔），不再把「写成功」当作「设备已收下」；写块失败按同地址重发（默认 3 次、间隔 50ms），失败提示区分「仍在 ISP 模式可直接重试」与「已退出 ISP，需断电重新上电」。
- 节奏：撤掉错判时期为规避丢帧而加的 20ms 保守间隔，恢复参考实现的 **1ms** 帧内报告间隔，与 Windows 一致。
- 实测（2026-10-14，同一块板、同一份 414 块步兵固件）：应用链路 **414/414 块 + 复位，6.33 秒，零失败**；此前 20ms 保守节奏需 22 秒。
- 全过程、根因证据与规避要点见 [docs/pitfall/HID烧录写块无响应.md](docs/pitfall/HID烧录写块无响应.md)。

**Linux：应用内一键安装 udev 规则**

- 「编译与烧录」页检测到 hidraw 规则缺失时，可直接一键安装：走 `pkexec` 弹出系统授权对话框，写入 `/etc/udev/rules.d/70-pieblock-hid.rules` 后自动加载；缺少 `pkexec`、授权失败或超时会给出对应提示。
- 命令行方式保留：`sudo tools/install_udev_rules.sh`（幂等），供无图形会话或未安装 polkit 的环境使用。

**调试提示音：步序旋律 + 卡农完成音**

- 每个测试项的开始音改为**上行音型的前 N 个音**（第 N 项就播 N 个音，个数即序号），第 6 项起整体升高八度表示进位；结束改用同一音型的**对称回落**。听感上每项是一句「上去、回来」的完整乐句，不再靠数「嘀」猜进度。
- 删掉旧的「开始区」前奏（完整音型播两遍属冗余），每项提示缩短约 1.6 秒。
- **全部完成**音改为《帕赫贝尔 D 大调卡农》全曲（多声部归并为单音线，854 音、约 5 分钟，每 2 秒循环），与逐项短乐句在长度与复杂度上一听即分。
- 新增**提示音风格**（标准 / 紧凑）与项目字段 `cue_style`：紧凑风格是标准风格每个时值精确减半（速度翻倍），音高与编码方式不变；旧项目文件缺该字段时按标准读取。
- 调试页新增**提示音试听面板**（可逐项试听、切换风格，按钮标注「第 N 项 · 低/高音区 · 上行 N 声」）与听辨口诀说明。试听与固件共用同一份曲线数据（`DebugCues`），听到的就是烧录后的效果，避免两边定义漂移。
- 摩擦轮激活期静音、斜坡期间「蜂鸣频率 = 当前占空比」的扫频提示保留不变。
- 方案背景与音高编码见 [docs/design/调试模式提示音方案.md](docs/design/调试模式提示音方案.md)。

**摩擦轮：静止启动先做 1000ms 电调激活**

- **步兵**：摩擦轮从静止（占空比 0）启动时，先保持 `500` 启动占空比完成电调激活，再进入原有 ±1 斜坡。时长按主循环整圈折算，实际不短于 1000ms，修复「无刷电调从静止直接爬坡容易起不来」。
- **调试**：摩擦轮测试项的激活阶段由 500ms 改为 1000ms，与步兵统一同一套激活流程。
- 激活期间不驱动蜂鸣器；关闭摩擦轮时立即取消激活残留，直接走停机斜坡。
- 说明同步到 [RM 电控指南](docs/guides/RM电控指南.md) 与 [STC32G 固件约束](docs/reference/STC32G固件约束.md)。

**Linux 烧录与诊断工具链（stcflash）**

- 新增 `stc32g/toolchain/stcflash/linux_hidraw_flash.py`：零依赖（hidraw + ioctl）的 Linux 烧录/诊断脚本，支持 `--probe-only` 探活、`--report-gap-ms` 节奏实验、`--blocks-per-session` 分批重开会话、`--no-erase --start-block N` **断电后从断点续烧**（闪存内容非易失，无需重新擦除）。
- 新增 usbmon 文本抓包分析器；修正 `flash_hex` 的速率统计；烧录日志标明本次生效的报告间隔。
- 新增无 GUI 的真机验证入口（`packages/pieblock_hid/tool/flash_hex.dart`），走与应用内 `HidFlasher` 相同的 Dart 链路。

**Android：新增构建流水线，首次提供安装包**

- 新增 Android 构建流水线：构建 Release AAB 与同时含 `arm64-v8a`、`x86_64` 两套 ABI 的通用 APK，校验包内 `.so` 的阶段对象哈希、许可证与资源清单，并随 `v*` 标签发布。
- 阶段对象用 `-ffile-prefix-map` 归一化临时构建路径，本地与 CI 跨机器逐字节可复现；基线校验失败时自动取证。
- 签名：配置 `ANDROID_KEYSTORE_*` Secrets 后产出正式签名包；**未配置时按 Flutter 模板惯例退回 debug 签名**（可安装验收、不可上架），CI 会给出显式告警。

**FreeRTOS：STC32G12K128 移植到 SDCC MCS-251（仓库侧）**

- 导入 FreeRTOS V10.4.6（STC 移植版 V1.0.2），端口层重写为 SDCC MCS-251，移除 Keil 工程文件、Keil 专有库与 USB CDC 示例。
- 新增 SDCC 构建脚本（`freertos/build.sh` 与 `freertos/build.ps1`）、构建清单与布局校验、端口帧序与源码契约测试，以及 [freertos/README.md](freertos/README.md)。
- 属仓库内的参考实现与构建链路，**不影响应用内编译出的固件**。

**文档**

- `docs` 重组为分类目录（`guides` / `reference` / `design` / `releases` / `pitfall` / `playbook` / `legal` / `examples` / `assets`）并新增总索引 [docs/README.md](docs/README.md)。
- 新增 [拓展板通信排障（playbook）](docs/playbook/拓展板通信排障.md) 与 [HID 烧录写块无响应（pitfall）](docs/pitfall/HID烧录写块无响应.md)。

## 升级提示

- 项目文件格式仍为 **16**，1.2.x 保存的 `.pieproj` 可直接打开；本次只新增可选字段 `cue_style`，**没有破坏性格式变更**。
- 步兵用户：摩擦轮启动多出 1 秒激活阶段，**需要重新编译并烧录**才会生效（旧固件行为照旧）。
- 调试用户：提示音与 1.2.1 完全不同（步序旋律、卡农完成音），同样需重新编译烧录才能听到新提示音。
- Linux 用户：本版本修复了烧录中途失联的根因，建议直接升级；旧版本遇到该故障时只能断电重上电。

## 已知限制

- Windows 安装包**未做代码签名**，SmartScreen 可能提示「未知发布者」，选择「仍要运行」即可。Linux 侧只提供 tar.gz，未做发行版原生包与桌面集成。
- **Android 包可用于项目的配置、编辑与预览，但不能编译固件**：应用内在 Android 上关闭了本地编译（SDCC 多进程管线的 Release 开关未启用）；USB-HID 烧录已接入且协议与 Windows 一致，但受 STC32G ROM ISP 固件对用户态 USB 主机的兼容性限制，真机实测无法烧录。未配置签名 Secrets 时产物为 debug 签名，仅适合安装验收与存档。
- 《卡农》完成音按原谱输出，低音进行段（约 73～147Hz）在无源蜂鸣器上听感很弱——这是与用户约定的取舍，未做移调或裁剪。
- 汇编输出目前仅音乐项目，步兵 / 工程 / 调试仍只生成 C 代码。
- 使用 Keil 编译需要本机已安装并授权 Keil C251（仅 Windows）；使用内置 SDCC 则无此要求。
- Web 版是只读演示：可以配置项目、查看生成的 C 代码，**不能编译或烧录**。
- 主控板为 STC32G（STC32G12K128）。
