# PIE-Block 1.2.0

新增 **Linux x64 桌面版**，并带来汇编输出（试点）、摩擦轮比例值控制与官网在线体验；同时修复了实机验证中发现的云台舵机、底盘摇杆方向问题。

## 下载

| 文件 | 说明 |
| --- | --- |
| `PIEBlock-1.2.0-windows-setup.exe` | Windows 安装包，双击按向导安装 |
| `PIEBlock-1.2.0-windows-x64-release.zip` | Windows 免安装版，解压后运行 `PIE-Block.exe` |
| `PIEBlock-1.2.0-linux-x64.tar.gz` | Linux 免安装版，解压后运行 `pieblock_app` |

三种形态都内置离线 SDCC C251 工具链与 STC32G 固件模板，**无需另外安装编译器**即可编译并烧录步兵、工程、调试与音乐四类工程。

Linux 首次烧录前需要授权 hidraw 设备（tar.gz 顶层附有 `70-pieblock-hid.rules`）：

```bash
sudo install -m 644 70-pieblock-hid.rules /etc/udev/rules.d/
sudo udevadm control --reload && sudo udevadm trigger --subsystem-match=hidraw
```

在仓库里则直接运行 `sudo tools/install_udev_rules.sh`（幂等）。规则用 `TAG+="uaccess"` 把设备授权给当前登录会话，应用无需 root 运行。

## 主要变化

**Linux 桌面版**

- 新增 hidraw 原生传输层（`libpieblock_hid.so`）：枚举 `/dev/hidraw*` 按 VID `34BF` / PID `1001` 匹配、`O_RDWR` 打开、收发 64 字节报告；取消用 `poll(hidraw + eventfd)` 即时打断阻塞读且句柄保持打开，读前预排空以对齐 Windows 的 `CancelIoEx` 语义，零第三方依赖。
- 烧录链路按平台接线：默认库名按平台解析 `.dll` / `.so`，向导的烧录按钮与主控板 USB-HID 分区向 Linux 放开，并给出 udev 安装指引。
- `flutter build linux --release` 直接产出自包含 bundle，`data/pieblock_runtime`（内置工具链 + 固件模板 + Keil 参考工程）由 CMake 在构建时装入；发布 tar.gz 因此从 31.8MB 收敛到约 21MB，与 Windows 同构。
- 随包附 `linux/udev/70-pieblock-hid.rules`。

**摩擦轮比例值控制**（步兵 / 调试）

- 摩擦轮改为以 **0–100% 油门比例值**为唯一控制量，不再直接指定占空比真值：`duty(引脚) = 500 + 油门% × (该引脚满油上限 − 500) ÷ 100`。`500` 是电调启动信号，固定不可调，同时作为映射下界。
- P64 与 P66 各自配置满油上限（500–800 的整百值），用来补偿两侧机械差异导致的转速差。引脚是唯一真相源，配置里不引入左右侧概念。
- 每次按键的调速步长由「占空比步长」改为「百分比步长」（1–100）。
- 平滑渐变仍跑在占空比上，两侧各自以 ±1 duty/主循环逼近各自目标，duty 变化率约 50/s，为《RM 电控指南》≤100 duty/s 上限的一半（若对比例值做斜坡，上限 800 的一侧会放大到 150 duty/s 而越界）。启停仍跳过 0~500 的无效区间。
- 向导「控制与摩擦轮」区改为按引脚配置，并新增**「油门换算速查」**：按当前两个上限实时列出 0/25/50/75/100% 对应的两侧占空比，便于按实测转速标定；复核页的调试项摘要同时给出油门与换算后的占空比。

**汇编输出（试点：音乐项目）**

- 代码生成器新增 `OutputTarget.asm`：音乐项目可生成与 C 版 `main.c` **行为一致**、可直接参与 SDCC 构建（sdas251 汇编 → 链接 → HEX）的 `main.asm`，保留中文注释，函数与 C 版一一对应。
- 生成代码页新增「输出语言：C 代码 / 汇编」切换（仅支持的项目类型显示），导出文件名随之为 `main.c` / `main.asm`；代码预览对汇编使用按本项目实际产出定制的 AS251 语法着色。
- 构建管线 `BuildRequest` 新增 `outputTarget`：主源文件改由 `sdas251 -l -o` 汇编，其余源文件仍由 sdcc 编译，链接与产物校验逻辑不变。
- 新增 [docs/guides/汇编生成器.md](docs/guides/汇编生成器.md)，记录实测的 C251 调用约定、main 模块骨架要求与汇编器语法注意，供后续推广到步兵 / 工程 / 调试项目复用。

**Web 版与官网**

- 应用可编译到 Web：配置向导与代码生成可以在浏览器里跑。平台差异统一收在 `lib/src/platform/` 下用条件导入选择实现（设置落 localStorage、导出走浏览器下载、音乐试听波形渲染退化为当前线程）。
- Web 版强制暗色、项目存浏览器 localStorage（项目名即文件名），导入导出走文件上传下载，与 Android 的「引用即身份」同一套思路。
- 官网英雄区直接嵌入在线体验并新增全屏按钮，工作流区换成真实界面截图，顶部导航改为悬浮 dock，下载按钮直链安装包而非 Release 页面。

**项目文件**

- `.pieproj` 格式升级到 **16**，步兵配置新增 `friction_p64_max_duty` / `friction_p66_max_duty` / `friction_level_step`。**格式 15 及更早版本不兼容**，见下方升级提示。

**固件生成（修复实机方向问题）**

- 修正**云台舵机方向设置不生效**：Yaw / Pitch 在舵机驱动下未把「方向」应用到摇杆增量，导致切换方向后云台仍与拨杆反向；现按 `direction` 对增量取反，与电机分支一致。
- 修正**底盘摇杆两轴极性相反**：实机（四轮正向默认配置）验证发现左摇杆 Y（前后）与 X（转向）极性均与模板假设相反，需旋转手柄 180° 才能正常操控；现两轴同时取负，并同步翻转步兵方向键覆写（move / sprint）的符号，步兵与工程模板一并修复。
- 摩擦轮方向固定为正向。

**构建与发布**

- 新增 Linux CI/CD（`linux.yml`）：工具链编译带缓存、bundle 完整性校验、**用打包产物做端到端固件编译冒烟**、传输层 `.so` 的 FFI 加载冒烟，并参与 `v*` 标签发布。
- Windows 与 Linux 两条流水线的 release 步骤统一为幂等模式（Release 已存在则补传产物），同一标签上两条流水线的产物可共存。

## 升级提示

- **1.1.0 保存的 `.pieproj` 在 1.2.0 中打不开**：格式 16 与 15 不兼容，应用会拒绝打开并提示在对应旧版 PIE-Block 中处理，**不做自动转换**。需要保留旧配置的同学，请先用 1.1.0 打开旧项目对照重建（建议先截图存档），或保留一份 1.1.0 并存使用。
- 同理，1.2.0 新生成的项目文件也无法在 1.1.0 中打开。

## 已知限制

- Windows 安装包**未做代码签名**，Windows SmartScreen 可能提示「未知发布者」，选择「仍要运行」即可。Linux 侧只提供 tar.gz，未做发行版原生包与桌面集成（无 `.desktop` 条目）。
- Linux 烧录需先安装 udev 规则（见上），Windows 插上即用。无 systemd / uaccess 的环境，可把规则里的 `MODE` 改为 `0666` 后重新插拔设备。
- 汇编输出目前仅音乐项目，步兵 / 工程 / 调试仍只生成 C 代码。
- 使用 Keil 编译需要本机已安装并授权 Keil C251（仅 Windows）；使用内置 SDCC 则无此要求。
- Web 版是只读演示：可以配置项目、查看生成的 C 代码，**不能编译或烧录**（浏览器里既没有本地工具链，也访问不到 USB-HID）。
- 本次不提供 Android 包：Android 侧仅音乐项目可配置、编辑、预览与编译，烧录受固件入场时序限制不可用；步兵 / 工程的离线 SDCC 仍在多进程真机黄金验证，Release 安全门通过前不对用户开放。
- 主控板为 STC32G（STC32G12K128）。
