# PIE-Block 1.1.0

跨平台分步式机器人代码生成器的首个公开发布版本，本次提供 **Windows x64 桌面版**。

## 下载

| 文件 | 说明 |
| --- | --- |
| `PIEBlock-1.1.0-windows-setup.exe` | 安装包，双击按向导安装 |
| `PIEBlock-1.1.0-windows-x64-release.zip` | 免安装版，解压后运行 `PIE-Block.exe` |

两种形态都内置离线 SDCC C251 工具链与 STC32G 固件模板，**无需另外安装编译器**即可编译并烧录步兵、工程、调试与音乐四类工程。

## 主要变化

**步兵云台**
- Yaw 与 Pitch 轴改为执行器列表：每个轴可挂 1~N 个执行器，舵机与电机可混用，每个执行器独立配置 IO、方向与舵机归中偏移；也可以留空表示不配置该轴。用于双舵机并联增扭、同轴双电机等机械结构。
- 新增可选「反向拨弹键」：按住期间拨弹电机按相反方向持续转动，松开立即停转。

**工程**
- 按键舵机支持 `direct` 预设点位模式：按键上升沿直接到达相对中位点的目标角度。

**项目文件**
- `.pieproj` 格式升级到 **15**。格式 14 及更早版本不兼容，应用会拒绝打开，需要在旧版本中导出配置后重建。

**固件生成**
- 修正 SDCC 串口整帧发送的残留问题，改为逐字节可靠发送；步兵遥控信道固定为 3。

**构建与发布**
- 新增 Windows CI/CD：push / PR 自动跑静态分析、单元测试与构建，每次构建都校验 6 条黄金固件哈希（保证 Windows 与其它平台编译出的固件逐字节一致）；推送 `v*` 标签自动发布本页 Release。

## 已知限制

- 安装包**未做代码签名**，Windows SmartScreen 可能提示「未知发布者」，选择「仍要运行」即可。
- 本次仅发布 Windows 产物；Android 侧离线编译的安全门尚未在真机上复核，暂不提供 Android 包。
- 使用 Keil 编译需要本机已安装并授权 Keil C251；使用内置 SDCC 则无此要求。
- 烧录通过 USB-HID，仅 Windows 支持；主控板为 STC32G。
