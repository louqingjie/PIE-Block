# PIE-Block 1.8.0-alpha.1（内测）

这是 **内测版（alpha）**，用于验证两块新能力：**工程按键动作表** 与 **遥控反馈蜂鸣**；同时项目文件格式升到 **18**。

alpha 阶段的格式与交互仍可能调整，正式版以 1.8.0 为准；内测反馈请附上工程文件。

**Android 内测包说明**：仓库尚未配置发布签名 Secrets，内测标签按规则退回 debug 签名并允许校验与上架检查跳过。装过正式版 1.7.0 的手机需要先卸载再装（签名不同），内测包也不可上架应用商店。Android 版仍只支持配置、编辑与预览，不能在本机构建固件。

## 主要变化

**工程按键动作表**

- 动作映射页「添加动作」右侧新增「添加动作表」：一个按键循环切换一组档位，每一档是表格的一列完整输出。
- 表格按「引脚 × 档位」编辑：舵机填带符号相对角度（−90°–+90°），电机填带符号 duty（−10000–10000）；档位数 2–8。
- 可选「上一档键」反向循环；上电后第一次按键进入第 1 档，切模式清零；每次切档响一声与档位对应的提示音，不看屏幕也能听出第几档。
- 校验器拦住表键/引脚与模式切换键、动作行、其他动作表的冲突，以及摩擦轮/未使用引脚、缺格与越界。

**遥控反馈蜂鸣**

- 收到第一帧遥控数据响高音（1319 Hz），按键或摇杆离开死区响短音（1568 Hz），约 1 秒收不到数据响低音（392 Hz），重连再响高音。
- 与启动诊断、模式切换、舵机位置音共用 P33，受「禁用蜂鸣器反馈」总开关控制。

**触发语义更清楚**

- 控制方式标签直接带后缀：电机按键「直接（按住）」、舵机按键「直接（按下）」、摇杆「直接（跟随）」、`单次（按下）`、`持续（按住）`、`启停（按下）`、`油门单次（按下）`、`油门持续（按住）`；动作卡片底部附一行说明。

**项目文件格式 18（向下兼容）**

- 新版可读格式 17 的旧存档：动作表缺省为空，生成代码与旧版一致；编辑保存后自动按 18 写回。
- 旧版 PIE-Block 打开 18 文件会提示升级，不会静默丢字段。
- 四份模板与六个教材示例已重存为格式 18。

## 已知限制

- alpha 阶段不保证格式 18 的字段不再变化；如遇格式调整，新版本会继续保证能打开旧存档。
- 桌面端 SDCC 黄金基线尚未按本次生成器改动重刷（不影响安装包使用，验收流程中会补）。
- 动作表为「写一次、保持」语义，电机类关节没有位置反馈，只能锁存 duty；机械臂请配合限位与低速调试。
