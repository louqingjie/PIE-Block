# PIE-Block 1.8.0-beta.2（公测）

这是 1.8.0 的第二轮 **公测版（beta）**，取代 1.8.0-beta.1。本版修复公测反馈最集中的一个
问题：动作行「单次 / 持续」等带符号参数输不进负号，导致舵机无法反向；同时把
《PIE-Block 软件与应用（简明版）》教材与全向底盘示例补齐。**项目文件格式仍为 22**，
与 beta.1 完全兼容，模板与示例工程无需重存。

仍属预发布版本：格式 22 的字段在本轮公测后如需调整，新版会继续保证能打开 22 的存档；
正式版以 1.8.0 为准。反馈请附上工程文件与「检查与摘要」页的错误信息。

## 主要变化（自 1.8.0-beta.1 起）

### 修复：带符号参数输不进负号

公测反馈：“只有‘直接输入’模式能输入符号，‘单次’和‘持续’都不行”。确认是界面缺陷：

- 小数参数框（「单次」「持续」的灵敏度 °/周期）输入白名单不含负号，填 `-1.5` 会被
  回退成 `1.5`；这两种舵机控制方式因此完全无法反向，而校验规则与代码生成都支持负号。
- 整数参数框（目标角度、转速等）虽然能用键盘敲出负号，但软键盘没有负号键，触屏设备
  上同样无法输入；动作表档位框还允许 `30-` 这类中间负号，界面显示与存档值会不一致。
- 现在按参数是否带符号选择键盘与输入白名单：动作参数（直接、增量、单次、持续、
  摩擦轮油门单次 / 持续）、调试测试项速度、PWM 舵机中位与云台归中偏移都能输入负数；
  摇杆速度、加速度、启停油门等本就不接受负值的字段仍会拒绝。动作表档位框一并收紧。
- 动作卡片说明补充“角度 / 灵敏度填负数即反向”。1.8.0-beta.1 起取消「方向」下拉、
  改用正负号是设计变更（见该版发布说明），不是功能缺失。

### 补记：beta.1 标签里的摩擦轮降档修复

beta.1 的 Release 构建（标签 `v1.8.0-beta.1`）还包含一处当时发布说明漏写的修复：
格式 19 把方向并入参数正负后，「油门单次」生成的降档语句被写成空表达式，升 / 降档键
按下油门不动。现已改为赋值并补上生成代码断言。使用摩擦轮升降档的项目请确认固件是按
beta.1 或本版重新生成的。

### 新增《PIE-Block 软件与应用（简明版）》

- 面向首次使用的参赛队员，独立主文件 `book/main-concise.tex` 与 `book/chapters/concise/`，
  只保留必要操作步骤，不含程序、汇编与实现细节；用 XeLaTeX 编译 `main-concise.tex` 即可。
- 补齐全向底盘 / 麦轮解算与动作表示例：麦轮与全向轮改用右摇杆控制转向，动作行直接
  使用内置输入填写轮速表达式，示例截图按新版界面重拍。
- 说明动作行的分层变量写法与变量名不能与内置名冲突；遥控器与底盘的通用章节抽离复用。
- 新增公测新功能演示帧生成器（`tool/beta_gif_frames_test.dart`），仅用于制作演示素材，
  不影响安装包。

## 升级提示

- **存档格式仍是 22**：beta.1 的工程可直接打开，不需要重建配置；旧版 PIE-Block 打开
  22 文件仍会提示升级，不会静默丢字段。
- **一般不需要重刷固件**：本版没有改动代码生成与固件逻辑。但若之前因为输不了负号而把
  「单次 / 持续」配成正数绕行，改成负数后请重新生成并烧录一次；摩擦轮升降档配置请
  按上节补记确认。
- 便携版首次启动仍需 1–2 秒解压；换版本会新建解压目录，旧目录不会自动清理。应用设置
  仍保存在系统应用数据目录。

## 已知限制

- Windows 安装包、便携版与免安装 zip **均未做代码签名**，SmartScreen 可能提示“未知发布者”，
  选择“仍要运行”即可；Linux 只提供 tar.gz，未做发行版原生包与桌面集成。
- Android 公测包为 debug 签名，不可上架应用商店，也不能在本机构建固件。
- Web 版是只读演示：可以配置项目、查看并导出生成的 C 代码，**不能编译或烧录**。
- 使用 Keil 编译需要本机已安装并授权 Keil C251（仅 Windows）；使用内置 SDCC 则无此要求。
- 动作表是“写一次、保持”语义：电机类关节没有位置反馈，只能锁存转速；机械臂请配合
  限位与低速调试。
- 教材示例工程按当前格式与截图生成，但示例控制律不承诺适配具体车体：引脚分配、电机
  方向、舵机中位都要按实车重新核对后再烧录。
