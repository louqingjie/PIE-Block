# PIE-Block 1.8.0-beta.1（公测）

这是 1.8.0 的 **公测版（beta）**，取代此前的两轮内测（alpha.1、alpha.2）。从 1.7.0
起累计的全部改动都包含在本版中：工程项目新增**按键动作表**、摩擦轮扩展到全部输出脚、
方向改用正负号、引脚备注，存档格式由 **17 升到 22**；界面与生成器修复了同引脚多行
互相清零导致的「反向键按下没反应」；桌面端内置 SDCC 改为增量复用目标文件，二次编译
明显加快。教材已按新版界面重拍全部截图并补入手柄面板配图。

仍属预发布版本：格式 22 的字段在本轮公测后如需调整，新版会继续保证能打开 22 的存档；
正式版以 1.8.0 为准。反馈请附上工程文件与「检查与摘要」页的错误信息。

Android 版仍只支持配置、编辑与预览，不能在本机编译固件。

## 主要变化（自 1.7.0 起）

### 工程按键动作表

一个按键循环切换一组档位，每一档是表格中的一列完整输出，适合机械臂抓放、多档位伸缩等
“一个键走完一段流程”的关节。

- 动作映射页“添加动作”右侧新增“添加动作表”；表格按“引脚 × 档位”编辑，档位数 2–8 档，
  舵机填带符号相对角度（−90°–+90°），电机填带符号转速（−10000–10000）。
- 可选“上一档键”反向循环；上电后第一次按键进入第 1 档，切模式清零；每次切档响一声
  与档位对应的提示音，不看屏幕也能听出第几档。
- 新增“越界重复”开关（格式 22）：默认开启以保持循环语义；指定“上一档键”后可关闭，
  关闭时下一档键停在最后一档、上一档键停在第一档。只有下一档键时校验器拒绝关闭。
- 支持整表复制：卡片头部的“复制动作表”保留按键、档数与全部单元格，副本插入到源表之后，
  复制后需重新选择按键或引脚以避免冲突。
- 档位 6–8 档超出卡片宽度时显示横向滚动条，可直接拖动查看后面的档位。
- 校验器拦住表键/引脚与模式切换键、动作行、其他动作表的冲突，以及摩擦轮或未使用引脚、
  缺格与越界。

### 修复：同引脚多行动作互相清零

工程模式下两行动作输出到同一个电机引脚时（例如 B 反向、C 正向），旧的生成器让后一行
在按键未按下时把前一行刚写入的值清成 0，表现为“反向键按下没反应”。

- 同一引脚的多条“直接”行现在按行序合并成一条 `if / else if / else` 链：行序在后的优先，
  全部松开归零；单行配置的生成结果逐字节不变。
- “直接”与“速度/增速”混用、两条表达式行写同一引脚等仍按行序覆盖的组合，校验器给出
  “在本模式被多行输出”的警告。

### 工程摩擦轮扩展到全部输出脚

- 工程项目的 P60/P62/P64/P66/P74/P75/P76/P77/MP03/MP74 十个输出脚均可选择摩擦轮角色；
  所有摩擦轮脚共享同一油门，并按各自的满油上限换算占空比。
- PWM 页按引脚实际角色显示满油转速输入框，不再限定 P64/P66；动作映射的主控板输出在
  摩擦轮角色下同样可选。扩展脚需为 50 Hz，MP03/MP74 固定 50 Hz；两组 PWM 都设为
  10000 Hz 时界面会提示舵机与摩擦轮不可用。
- 加减速斜坡期间按当前占空比蜂鸣：激活期静音，斜坡中频率跟随第一个摩擦轮脚的当前占空比，
  到达目标后静音；受“禁用蜂鸣器反馈”总开关控制。
- 油门方向控件改为“增减”语义，避免被误读为正反转。

### 方向改用正负号（格式 19）

- 动作行与调试测试项取消“方向”下拉，直接用带符号的数值表示方向：正数按默认方向，
  负数反向，用来在不改接线的情况下纠正转向。界面数值标签统一称“转速”。
- 动作表档位输入框与引脚框同宽，并按引脚角色提示角度或转速。
- 格式 17、18 的独立 `direction` 字段在读取时自动折算为正负号，生成代码不变。

### 引脚备注（格式 20）

- 工程 PWM 页的“引脚输出角色”为每个已使能引脚增加选填备注，未使用或未选择角色的引脚
  不显示备注框。
- 动作行“输出”与动作表引脚下拉显示为“MP03（工程一级舵机）”，超长标签省略显示；
  备注不参与校验与代码生成。

### 项目名称改由文件名派生（格式 21）

- 格式 21 起存档不再写 `name` 字段，界面标题与最近项目只取文件名，改文件名即改项目名。
- 打开 17–20 的旧存档时自动重写为当前格式，写回失败只提示、不阻止打开；旧字段在读取时
  被忽略。

### 其他界面与工程改动

- 工程主控板 MP03/MP74 的输出角色可在“舵机”与“未使用”之间选择；未使用时不再校验
  中位/限幅、隐藏对应输入，动作行引用该口会报错，代码生成也不再初始化该口。
- 控制方式标签直接带触发后缀：电机按键“直接（按住）”、舵机按键“直接（按下）”、摇杆
  “直接（跟随）”、`单次（按下）`、`持续（按住）`、`启停（按下）`、`油门单次（按下）`、
  `油门持续（按住）`，动作卡片底部附一行说明。

### 构建更快：SDCC 目标文件增量复用

- 桌面端构建按“缓存版本 + 工具链/固件指纹 + 工程 + 源文件路径”缓存 `.rel` 与 `.lst`，
  `main.c` 始终重新编译；复用前校验对象与列表的大小和 SHA-256，缓存损坏自动回退全量编译。
- 缓存写入失败不阻断构建，旧指纹目录自动清理；构建日志标注“复用缓存”并汇总复用/重编
  模块数，HEX 哈希与全量构建一致。

### 教材与文档

- 教材全部软件截图按新版界面重拍；第 2 章截图纳入自动生成脚本，与固件构建产物一致。
- 新增《教材写作规范》，全书措辞统一为正式书面语体；第三章补入手柄面板标注配图，修正
  LC/RC 为摇杆按下开关。
- 文档补充格式 19–22 的迁移说明、动作表方案、正式发布后的存档兼容策略与增量构建说明。

### 未纳入本版的改动

- 内测版曾加入“遥控输入与链路蜂鸣反馈”（收到第一帧、摇杆离开死区、断线时蜂鸣）。实测
  每次按键会阻塞约 25 ms 蜂鸣，遥控操作明显不跟手，本版已完整移除该功能及其板级库改动。

## 升级提示

- **存档格式从 17 升到 22**：可读入格式 17–21 的旧存档，打开后按 22 写回；格式 16 及
  更早需要重建配置。旧版 PIE-Block 打开 22 文件会提示升级，不会静默丢字段。
- **必须重新生成并烧录**：动作行与调试测试项的方向改为正负号，摩擦轮覆盖范围、同引脚
  合并逻辑与主控板输出角色都会改变生成的固件，旧固件不能继续使用新配置。
- 依赖旧“方向”下拉的截图与笔记需按新界面（带符号转速）核对；教材与示例工程已同步更新。
- 同引脚多“直接”行的合并会让原先“后行覆盖、松开清零”的配置行为发生变化，请在实车上
  重新验证反向键与组合键。
- 便携版首次启动仍需 1–2 秒解压；换版本会新建解压目录，旧目录不会自动清理。应用设置
  仍保存在系统应用数据目录。

## 已知限制

- Windows 安装包、便携版与免安装 zip **均未做代码签名**，SmartScreen 可能提示“未知发布者”，
  选择“仍要运行”即可；Linux 只提供 tar.gz，未做发行版原生包与桌面集成。
- Android 公测包为 debug 签名，不可上架应用商店，也不能在本机构建固件。
- Web 版是只读演示：可以配置项目、查看并导出生成的 C 代码，**不能编译或烧录**。
- 使用 Keil 编译需要本机已安装并授权 Keil C251（仅 Windows）；使用内置 SDCC 则无此要求。
- 动作表是“写一次、保持”语义：电机类关节没有位置反馈，只能锁存转速；机械臂请配合
  限位与低速调试。
- 调试序列启用超过 10 项时提示音会复用第 6–10 项音型，请以界面序号为准；同轴多舵机的
  限幅按各侧最紧值取交集。
- 教材示例工程按当前格式与截图生成，但示例控制律不承诺适配具体车体：引脚分配、电机方向、
  舵机中位都要按实车重新核对后再烧录。
