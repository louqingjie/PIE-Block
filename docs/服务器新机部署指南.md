# 编译服务器新机部署指南

目标：在一台**全新的、已装好 Keil C251 的 Windows 电脑**上，把云端编译服务
（keil_server + 可选 Cloudflare 公网隧道）完整部署起来，实现：崩溃自动重启、
开机自启、每 60 秒健康自愈、每日自动备份，且**不弹窗打扰日常使用**。

> 本机已经在跑的服务器不用看这篇；本指南用于换机器 / 重装系统后的一次性搭建。
> 全程约 30~60 分钟，其中公网隧道部分需要手动登录 Cloudflare。

## 一、准备清单

| 项 | 说明 |
| --- | --- |
| Windows 电脑 | Win10/11 均可（Win Server 也可以），需联网 |
| Keil C251 | **已装好并激活**（见下方「许可证提醒」） |
| 项目代码 | 编译服务在 `pie-block/keil_server/`，把整个项目拷到或 git clone 到本机 |
| 管理员账号 | 全程需要管理员权限（UAC 弹窗点「是」） |

### 许可证提醒（最重要）

Keil 许可证是**机器绑定**的。换新电脑后原许可证失效，必须在新机上重新申请：

1. 打开 `C:\Keil_v5\UV4\UV4.exe` → License Management 查看 **License ID Code**
2. 去 keil.com 注册账号，用该 LIC 领取免费的 C251 密钥
3. 密钥写入安装目录的 `TOOLS.INI`。**没有有效密钥时编译被限制在 2KB**
   （报 `RESTRICTED VERSION` / `ERROR L250`），服务会识别并提示，但无法正常编译
4. 申请完后用 `/health` 接口验证 `keil.license_ok` 为真

## 二、拷贝项目与安装依赖（约 10 分钟）

```powershell
# 1) 没有 Python 就装一个 3.10+（python.org 下载安装包，勾选 Add to PATH）
# 2) 在项目根目录创建虚拟环境
python -m venv .venv

# 3) 安装依赖（FastAPI、uvicorn 等）
.\.venv\Scripts\python.exe -m pip install -r keil_server\requirements.txt

# 4) 验证（预期连不上，属正常——服务还没起）
.\.venv\Scripts\python.exe -m keil_server.client health
```

路径建议**不含空格**，例如 `C:\Users\<你>\Desktop\program\pie-block`。

### 验证 Keil 能被探测到

```powershell
.\.venv\Scripts\python.exe -c "from keil_server import keil_detect; i=keil_detect.detect(); print(i)"
```

`available=True` 即可。若为 False，说明 Keil 装在非默认位置，安装服务时用
`-KeilPath` 指定（见第五节）。

## 三、安装 NSSM（约 5 分钟）

NSSM 负责「服务托管 + 崩溃自动重启」。

1. 下载：<https://nssm.cc/download>（选 win64 版）
2. 解压后把 `nssm.exe` 放到 `C:\nssm\nssm.exe`（固定位置，脚本默认找这里）
3. 验证文件存在即可。**不要手动跑 `nssm version`**——它在非控制台环境会挂起
   （安装脚本已内置防护）

## 四、公网隧道（可选，约 20 分钟，一次性）

> 只需局域网/本机使用（队友在同一 Wi-Fi，直接用 `http://<本机IP>:8000`）
> 可跳过本节。

完整步骤见 `docs/公网部署CloudflareTunnel指南.md`，浓缩版：

```powershell
# 1) 下载 cloudflared 到 C:\cloudflared\cloudflared.exe
# 2) 登录并创建隧道（浏览器会弹出授权）
cd C:\cloudflared
.\cloudflared.exe tunnel login
.\cloudflared.exe tunnel create pieblock    # 记住输出的 TUNNEL-UUID

# 3) 复制配置模板并填写 UUID 和凭证路径
copy C:\Users\<你>\Desktop\program\pie-block\keil_server\deploy\cloudflared-config.yml.example `
     C:\Users\<你>\Desktop\program\pie-block\keil_server\deploy\cloudflared-config.yml
#    用记事本打开，把 tunnel: 和 credentials-file: 两行改成你的实际值

# 4) 把域名解析到隧道（一次）
.\cloudflared.exe tunnel route dns pieblock build.pieblock.asia
```

> 凭证文件（`C:\Users\<你>\.cloudflared\<UUID>.json`）丢了要重新 login + create，
> 建议马上备份一份（见第八节）。

## 五、安装服务（约 5 分钟）

**以管理员身份**打开 PowerShell（开始菜单搜 PowerShell → 右键 → 以管理员身份运行），
进入项目根目录：

```powershell
# 只在本机/局域网用（不装隧道）：
.\keil_server\deploy\install_nssm.ps1 -SkipTunnel

# 或带公网隧道（推荐；管理员 key 不填会自动生成并保存到 data\admin_key.txt）：
.\keil_server\deploy\install_nssm.ps1
```

脚本自动完成：

- 探测 Keil 目录（`C:\Keil_v5` → `%LOCALAPPDATA%\Keil_v5` → `C:\Keil`），
  找不到就传 `-KeilPath "C:\你的路径"`
- 管理员 key 处理（参数 > 本地文件 > 自动生成并保存）
- **端口预检**：8000 端口被旧的手动实例占用时自动清理
- 注册服务 `PieBlockKeil`（编译服务）和 `PieBlockTunnel`（隧道）：
  崩溃自动重启、开机自启、日志写入 `keil_server\data\logs\`
- 最后自动请求 `/health` 验证

看到 `[OK] 健康检查通过：http://127.0.0.1:8000/health` 即成功。

> 脚本中任何一步失败会报红字 `[错误]` 并退出，把日志
> `keil_server\data\logs\install_console.log` 发给电控排查。

## 六、注册自动化任务（约 2 分钟）

```powershell
# 仍是管理员 PowerShell，在项目根目录：
.\keil_server\deploy\install_scheduled_tasks.ps1 -PublicUrl "https://build.pieblock.asia/health"
```

注册两个计划任务（**以 SYSTEM 账户运行，会话 0 无桌面，不会弹窗打扰使用**）：

| 任务 | 频率 | 作用 |
| --- | --- | --- |
| PieBlockHealthMonitor | 每 60 秒 | 探测 `/health`，连续失败 3 次自动重启服务；公网不可达时重启隧道 |
| PieBlockDailyBackup | 每天 03:00 | 备份 key 表、管理员 key、隧道配置与凭证到 `C:\pieblock-backup\` |

## 七、验证清单

```powershell
# 1. 两个服务都在运行
Get-Service PieBlockKeil,PieBlockTunnel

# 2. 本地健康检查（预期 keil.available=true, license_ok=true）
curl http://127.0.0.1:8000/health

# 3. 公网（装了隧道才看）
curl https://build.pieblock.asia/health

# 4. 计划任务就绪且是 SYSTEM 账户
Get-ScheduledTask -TaskName "PieBlock*" | Select TaskName,@{n="RunAs";e={$_.Principal.UserId}},State

# 5. 等 2 分钟后再查一次监控是否自动跑过（Result=0 为成功）
Get-ScheduledTaskInfo -TaskName PieBlockHealthMonitor | Select LastRunTime,LastTaskResult
```

全部通过 = 部署完成。客户端接入方式见 `keil_server/README.md`
（CLI / Godot `--remote` / MCP 三选一，只需配 `PIEBLOCK_KEIL_SERVER_URL` 和
`PIEBLOCK_KEIL_API_KEY`）。

## 八、日常运维速查

```powershell
# 查看服务日志（自动重启都会有记录）
Get-Content keil_server\data\logs\monitor.log -Tail 20
Get-Content keil_server\data\logs\keil-err.log -Tail 20

# 手动重启编译服务（升级代码后）
Restart-Service PieBlockKeil -Force

# 给队员分配 key（管理员权限）
.\.venv\Scripts\python.exe -m keil_server.keys list
.\.venv\Scripts\python.exe -m keil_server.keys add 张三

# 停止服务器并禁止自启 / 恢复（不删除服务）
.\keil_server\deploy\stop_server.ps1
.\keil_server\deploy\start_server.ps1

# 全量卸载（服务 + 计划任务）
.\keil_server\deploy\uninstall_nssm.ps1 -AlsoRemoveTasks
```

**备份与恢复**：每日备份在 `C:\pieblock-backup\<时间戳>\` 目录里。**务必定期把
备份目录拷到别处**（U 盘 / 私有仓库），里面是恢复必需的：`api_keys.json`
（用户 key 表）、`admin_key.txt`、`cloudflared-config.yml` 和隧道凭证。
换新机器时把这三个文件拷回原位置，key 表原样可用。

## 九、常见问题

| 症状 | 原因与解决 |
| --- | --- |
| `/health` 返回 `license_ok:false` 或编译报 `RESTRICTED VERSION` | 新机许可证未激活，按第一节重新申请 |
| 服务反复重启，`keil-err.log` 报 `bind ... 10048` | 端口被旧实例占用；重跑 `install_nssm.ps1`（会自动清理），或手动杀掉旧 python 进程 |
| 编译日志全是 `0 Error(s)` 但没生成 hex | 客户端没带 `-r` 全量重建；服务端代码已是 rebuild，检查客户端版本 |
| 计划任务不在运行 / LastTaskResult 非 0 | 用管理员重跑 `install_scheduled_tasks.ps1` |
| 公网打不开 | 检查 `PieBlockTunnel` 服务状态与 `tunnel-err.log`；Cloudflare 免费计划有请求量提示，正常用量够 |
| 想彻底换端口（如 8080） | `install_nssm.ps1 -Port 8080`，并同步修改 `cloudflared-config.yml` 的 ingress 与客户端 URL |

## 十、文件速查

| 文件 | 作用 |
| --- | --- |
| `keil_server/deploy/install_nssm.ps1` | 安装服务（幂等，可重复跑） |
| `keil_server/deploy/install_scheduled_tasks.ps1` | 注册监控 + 备份计划任务 |
| `keil_server/deploy/stop_server.ps1` / `start_server.ps1` | 停机 / 恢复 |
| `keil_server/deploy/uninstall_nssm.ps1` | 卸载服务 |
| `keil_server/deploy/monitor_health.ps1` | 健康检查与自动重启（计划任务调用） |
| `keil_server/deploy/backup_data.ps1` | 每日备份（计划任务调用） |
| `keil_server/data/logs/` | 所有运行日志 |
| `C:\pieblock-backup\` | 每日备份输出 |
