# 遥控反馈蜂鸣方案

## 目标

让操作者不看屏幕也能判断遥控链路与输入是否被主控收到。步兵、工程两种项目的
生成固件都带这套提示，**不新增配置项**，只受现有「禁用蜂鸣器反馈」总开关控制。

| 事件 | 音型 | 时长 |
| --- | --- | --- |
| 上电后第一帧有效遥控数据（链路连上） | 1319 Hz | 100 ms |
| 按键按下 / 摇杆离开死区 | 1568 Hz | 25 ms |
| 约 1 s 没有新的有效帧（掉线） | 392 Hz | 120 ms |
| 掉线后重新收到数据（重连） | 1319 Hz | 100 ms |

按键松开、摇杆回中**不发声**，避免持续操作时一路响。

## 为什么需要改板级库

板级库原本没有「收到帧」的可观测信号：

- `nrf_handler()` 读完 STATUS 立即清标志，`rc_ctrl` 也没有 `extern`，
  生成代码拿不到“刚刚收到一帧”；
- `TM4_Isr` 里的断线检测从未启用（`PIT_Timer_Ms(TIM4, 1)` 被注释掉），
  而且 `Clear_Time` 在收包路径不清零，直接启用会每 50 ms 清空遥控状态；
- P2.6 的 NRF IRQ 中断被生成代码主动关闭（`P2INTE &= ~GPIO_Pin_6`），
  库里的 `P2_INT_ISR_Handler` 又不处理 P2.6，走中断方案更脆。

因此在 `remote_control.c` 增加一个收包计数：

```c
volatile uint32_t rc_packet_count = 0;   /* Rc_unpack_data 校验通过后自增 */
```

Keil（`stc32g/Libraries`）与 SDCC（`stc32g_sdcc/libraries`）两套副本保持一致，
头文件导出 `extern volatile uint32_t rc_packet_count;`。

## 生成代码

`_remoteFeedback()` 为步兵/工程共用，插入在 `_header()` 之后；主循环在
`ReadControllerInputs()` 之后调用 `UpdateRemoteFeedback()`。

- 链路：`rc_packet_count` 变化即“收到新帧”，同时清零空闲计数；首次由 0 变非 0
  响连上音；空闲计数超过 `REMOTE_LINK_TIMEOUT_LOOPS = 33`（约 1 s）判定掉线。
- 输入：11 个数字键位图 + 4 个摇杆“是否离开死区”（`ReadControllerInputs()`
  已按死区归零），只对**上升沿**（新按下 / 新推出死区）发声。
- 工程多模式时，模式切换键（循环切换的 `modeSwitchKey`、一一对应的 `modeKeys`）
  不参与输入提示——它们已有 `ModeSwitchFeedback`，否则会双响。
- 模式切换的提示音最长阻塞约 1 s，切换分支里追加 `remoteLinkIdle = 0;`，
  避免这段阻塞被误判成掉线。
- `buzzerDisabled` 为真时整段不生成（此时 `BUZZER_CH`、`Beep()` 也不存在）。

## 取舍

- 蜂鸣是阻塞实现（`Beep()` 内部 `Ms_Delay`）：每次按键约 25 ms、链路事件
  100–120 ms 内主循环不发扩展板帧，执行器保持上一帧占空比。教学场景可接受；
  若以后要求零停顿，可改成“每轮递减的异步音”，并让
  `UpdateBuzzerFeedback()` / `UpdateServoFeedback()` 在发声期间让位。
- 掉线判定用主循环圈数近似时间（约 30 ms/圈），不是精确计时；模式切换等已知
  长阻塞点已重置计数。
- 工程舵机位置反馈用蜂鸣器音高表示占空比（250–1250 Hz），与本方案的
  392/1319/1568 Hz 不重叠，听起来可区分。

## 验证

- 单元测试：`packages/pieblock_core/test/pieblock_core_test.dart` 的「遥控反馈蜂鸣」。
- 运行时场景：`inf-remote-feedback` / `eng-remote-feedback`
  （`packages/pieblock_core/tool/verify_runtime.dart`，桩里用 `LINK` 伪输入控制收包）。
- 改动生成器/固件后黄金基线必然变化，需按
  `docs/design/android-sdcc-port.md` 的「重刷黄金基线」三步更新
  `android_sdcc_golden_matrix.dart` 的 `_baselineHashes` 与
  `tools/android_sdcc_baseline.json` 的 `windows_golden_sha256`。
