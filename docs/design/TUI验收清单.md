# PIE-Block TUI 验收清单（M0–M8）

本清单以仓库现状与自动化测试为证据，区分「已通过自动化验证」「需人工/硬件验收」与「未完成」。
每次发布前应逐项核对，未通过项不得隐藏，必须在 `docs/design/TUI复刻进度.md` 中保留说明。

## 自动化验证（可重复执行）

```powershell
cd tui
cargo fmt --all --check
cargo clippy --all-targets -- -D warnings
cargo test                 # 当前 149 个测试、31 个测试目标，全部通过
pwsh -File scripts/package.ps1 -SkipBuild   # Windows x64 发布包 + sha256
bash scripts/package.sh                     # Linux x86_64 发布包（CI 执行）
```

CI：`.github/workflows/tui.yml` 在 Windows/Linux 执行 fmt、clippy、全量测试、release 构建、
打包（校验无 Dart/Flutter 文件）并上传工件。

## 需人工/硬件验收（阻塞或待执行）

1. **真实主控板烧录**：连接 STC32G 主控板并进入 USB 下载模式，验证探测、擦除、写入、校验、复位、
   中断与重试；需要硬件，本机无板。
2. **终端人工清单**：
   - Windows Terminal 与 conhost：CJK/宽字符、IME 输入、鼠标滚轮/点击、恢复屏幕；
   - Linux（GNOME Terminal/konsole）：字体回退、鼠标、无多余动态依赖。
3. **Keil C251**：当前 Rust 工具链仅实现 SDCC；Keil 编译器路径与构建会明确提示「未移植」，
   需要 Keil 安装环境与构建产物对照。
4. **SDCC HEX 与 Flutter 桌面端一致性**：同一配置、同一工具链版本下比较 HEX/MAP 与 SHA-256；
   需要 Flutter 运行环境与固定工具链版本。
5. **旧存档回归**：格式 17–23 的 `.pieproj` 打开/保存字节一致性（goldens 已覆盖核心路径，
   仍需用发布版样本抽查）。
6. **音乐重叠/长时间曲目**：实际试听、固件容量预警的交互体验评估。
