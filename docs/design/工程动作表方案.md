# 工程按键动作表方案

> 状态：已实施（格式 18）。相关代码：`packages/pieblock_core/lib/src/models.dart`（`ActionTable`）、
> `validator.dart`（`_actionTables`）、`code_generator.dart`（`_actionTableCode`）、
> `lib/src/wizard/wizard_pages_engineer.dart`（`_ActionTableCard`）。

## 目标

工程项目里「一个键循环切换一组输出」的需求，典型场景是机械臂的多个位姿、
电机多档速度。原先把每个档位拆成独立动作行，既冗长又无法表达「同一个键
按第 N 下时用第 N 列的值」。

动作表把这件事变成一个显式的表格：**一个按键 = 一张表，每按一次前进一档，
每一档是表格的一列完整输出值**。

不采用「连击（按几下触发第几个动作）」：连击需要判定窗口，存在固有延迟与
漏计风险，和实时控制冲突；档位循环每次按下都是一个完整事件，没有窗口。

## 数据模型（格式 18）

```dart
class ActionTableRow {              // 表的一行 = 一个输出引脚
  final String? pin;
  final List<int?> values;          // 长度 = 档数；舵机=±角度，电机=±duty
}

class ActionTable {
  final String? id;                 // 稳定标识（列表 key / 删除）
  final String? key;                // 下一档键（必填，数字键）
  final String? previousKey;        // 上一档键（可选）
  final int? steps;                 // 2–8
  final List<ActionTableRow> rows;  // 至少 1 行
}
```

存放在 `EngineerModeConfig.actionTables`（按模式），JSON 字段
`modes[].action_tables`；为空时**不写出**，因此格式 17 存档读入再保存不会
凭空多出字段。

## 语义

- **写一次、保持**：切档时把整列值写入输出并保持。舵机保持角度、电机锁存
  duty，不是「按住才输出」。上电初始为 0（未选档），第一次按键进入第 1 档。
- **循环**：下一档键 `step = step >= N ? 1 : step + 1`；上一档键
  `step = step <= 1 ? N : step - 1`（首次按上一档键落到最后一档）。
- **按模式隔离**：每张表只在自己所属模式里响应；切模式时档位清零，
  这样回到该模式后第一次按键总是第 1 档。
- **提示音**：切档后 `Beep(880/1047/1319/1568/1975/2349/2637/2794 Hz, 80ms)`，
  档位与音高一一对应，短音不阻塞主循环；受「禁用蜂鸣器反馈」总开关控制。
- **单位**：舵机是带符号相对归中角度（−90–+90），写入时
  `_servoDuty(mid + angle)` 并按该引脚的限幅钳位；电机是带符号 duty
  （−10000–10000）。摩擦轮引脚禁止进入动作表（必须走摩擦轮安全斜坡）。

## 校验

- `steps` 必填 2–8；`rows` 至少一行；每个 `values` 长度等于 `steps` 且每格必填；
- `key` 必填且为数字遥控键；`prev_key` 若填必须是数字键且不等于 `key`；
- 两个键都不能是模式切换键，也不能出现在本模式动作行的输入里；同模式跨表不得重复；
- 表内引脚不得与本模式动作行或其他表重复；角色必须是舵机/电机/抖动电机，
  `unused`、`friction` 报错；
- 字段路径：`modes.{mi}.action_tables.{ti}.key|prev_key|steps`、
  `.rows.{ri}.pin`、`.rows.{ri}.values.{ci}`，问题面板可跳转到对应格子。

## 生成代码

每张表生成 `ApplyTableN(step)`（switch 档位）、`UpdateTableN()`（上升沿切档 +
提示音）；`UpdateActionTables()` 按 `currentMode` 分发；`ResetActionTables()`
在模式切换时清零。表引脚并入 `usedPins`，从而生成 PWM 初始化与主控板舵机的
周期输出。无动作表的工程生成结果逐字节不变。

## 兼容性（项目已正式发布）

- 写入格式 **18**，可读 **17–18**：17 存档缺少 `action_tables`，读入后按空表
  处理，生成代码与旧版一致；编辑保存后按 18 写回（自动升级）。
- 旧版 App 打开 18 文件会提示升级；新版不写回旧格式、不静默丢字段。
