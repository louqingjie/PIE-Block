# 发布前步兵/工程生成代码逻辑核对报告

> 状态：**全量验证通过**（2026-10-24）
> 范围：`ProjectKind.infantry` / `ProjectKind.engineer` 的配置校验、C 代码生成与生成代码运行行为
> 核对方法：静态审查（生成器/验证器/UI 意图三方对照）+ 排列组合枚举 + gcc 编译冒烟 + 生成代码宿主机执行（虚拟时钟 + 脚本化遥控输入 + 扩展板帧解码断言）

## 1. 核对手段

三层验证全部沉淀为可重复执行的资产：

| 层 | 内容 | 位置 | 依赖 |
| --- | --- | --- | --- |
| 结构层 | 枚举 197 个合法配置变体（一维全枚举 + 160 个随机全组合采样），生成 C 源码并断言括号平衡、槽位索引、全局声明唯一性、表达式标记路径 | `packages/pieblock_core/test/generated_permutation_test.dart` | 无 |
| 编译层 | 每个生成的源文件用 `gcc -fsyntax-only` 做编译检查（桩头 `tool/runtime_stub/main.h`，覆盖板级符号与 Keil 风格 `MATH.H`） | 同上（缺 gcc 自动跳过） | gcc |
| 执行层 | 生成代码与虚拟时钟 harness 一起编译成宿主机可执行文件：`Ms_Delay` 推进虚拟时间并按脚本施加遥控输入，串口字节流解码为扩展板帧（Init/Dir/Duty），对摩擦轮斜坡、拨弹脉冲、底盘混控、舵机行程/余量、模式切换、表达式求值等 12 个场景做时序与数值断言 | `tool/verify_runtime.dart`（CLI），同上测试（缺 gcc 自动跳过） | gcc |

复跑方式：

```powershell
cd packages/pieblock_core
dart run tool/verify_runtime.dart        # 三阶段全量
dart run tool/verify_runtime.dart --structural   # 仅结构层
dart test                                # 含永久回归与（有 gcc 时的）编译/执行场景
```

## 2. 发现并已修复的问题

### 2.1 生成器缺陷（执行级验证确认）

| 编号 | 问题 | 允许的触发配置 | 后果 | 修复 |
| --- | --- | --- | --- | --- |
| G1 | `PrepareMode` 把底盘槽无条件排除在归零之外 | 工程启用底盘 + 某模式不勾选「保留左摇杆底盘控制」 | 切到该模式后底盘电机以切换前的占空比**持续运转**，无停止手段（设计文档 §1 背景列出的安全隐患，此前只修了「底盘整体关闭」的释放脚） | 仅在 `preserveChassis` 的模式里豁免底盘槽；不保留的模式归零（保留模式因 `CalculateChassis` 每周期重写，归零无影响） |
| G2 | 电机「增速」（accelerate）模式增量无钳位累加 | 任意电机/抖动电机脚 + 摇杆轴 + 增速 | 满杆 4 个周期（约 80ms）即超出 ±10000 duty；目标机 `int` 为 16 位，继续打杆会回绕翻转方向位（执行验证中观测到 duty 64816） | 累加后钳位 ±10000，与表达式行的角色钳位同一上限 |

### 2.2 「被允许但会出现问题」的配置组合（校验器补拦截）

| 编号 | 组合 | 后果 | 拦截规则 |
| --- | --- | --- | --- |
| V1 | 步兵启用「按下左摇杆启用冲刺」+ 扳机/反向拨弹/摩擦轮键选 LC | 一次 LC 同时触发冲刺与该动作 | 冲刺启用时动作键不得为 LC |
| V2 | 步兵启用「按下右摇杆让云台归中」+ 任一动作键选 RC | 一次 RC 同时归中云台并触发动作 | 归中启用时动作键不得为 RC |
| V3 | 工程启用底盘冲刺 + 模式切换键或动作输入选 LC | 一次 LC 同时切模式/触发动作并让底盘冲刺 | 同 V1（切换键与动作输入分别报错） |
| V4 | 步兵方向键用途=冲刺 + 未填冲刺速度 | 「冲刺」箭头静默退化为普通速度移动 | 必填冲刺速度 |
| V5 | 工程/步兵变量名首尾带空格（UI 存原始文本，校验只查 trim 后的名字） | 生成 `pbv_ foo` 非法标识符；或 `foo` 与 `foo ` 跨模式重复声明 `pbv_foo` | 变量名首尾不能有空格；生成器同时统一按 trim 后名字兜底 |

### 2.3 核对通过（未改动）的关键语义

- 摩擦轮安全栈（步兵与工程同律）：静止启动先保持 500 duty 1s 激活，之后 ±1/周期斜坡；目标 0 时降到 500 直接停机（跳过 0~500 无效区间）；两侧按各自满油上限映射同一油门；启停/单次/持续/摇杆增量四方式的边沿与速率语义。
- 阻塞单发：脉冲期间先补发 Dir 帧再发 Duty 帧，`triggerTimeMs` 停摆后归零；视觉闭环 + 反向拨弹键的反向优先与松开归零。
- 底盘混控公式（含转向反转、冲刺、方向键移动/冲刺）、死区处理。执行验证中
  确认速度+转向满杆叠加时占空比可达 2×速度（如 6000+6000）；与培训模板参考
  实现 `ROBOMASTER_INFANTRY`（`-baseSpeed - turnSpeed`，同律不钳位）逐字一致，
  属参考实现固有行为，由拓展板侧处理，非生成器缺陷。
- 云台舵机行程（含限位交集）、归中；工程舵机按键单次/持续的小数余量进位（1.25°×3 = 20 duty 整数累进）。
- 模式切换：未映射电机归零、舵机保持、摩擦轮状态跨模式保持、按键沿同步防误触发。
- 表达式行：类型系统、先定义后使用、全局/局部变量提升、输出按角色钳位与舵机角度换算。
