# 智能交互手柄使用指南

本文档介绍比赛用智能交互手柄（遥控器）的结构、工作原理与编程方法。
手柄基于 **NRF24L01** 无线模块与主控板通信，支持双摇杆与多按键。

## 一、结构

- **USB 充电口**：为手柄内置电池充电
- **开关**：手柄电源开关
- **双摇杆**：左 / 右各一个，独立操作
- **更多按键**：A/B/C/D、方向键、功能键等
- 持握舒适，PCB 为定制设计

## 二、工作原理

- 遥控器使用 **NRF24L01** 芯片，采用 **SPI 通信协议**
- 模块自由：**同频段内自由收发**（发送端与接收端必须同通道）
- **摇杆**：单个摇杆两路 ADC 检测，12bit 检测精度，检测量程约
  `2047 → -2047`，开机自动归一化校准

## 三、接线与通道设置

接收端（主控板侧）需要 NRF24L01 模块，程序里必须设置与手柄一致的通信频道。

### 通道号怎么找？

手柄**开机后长按 mode 按钮**，屏幕会跳转到通道号显示页面，记下这个数字。

### 程序中设置通道

在 `nrf24l01.c` 库中设置：

```c
#define CHANAL 1
```

同时 `main.c` 中必须定义 `Channal` 变量（`nrf24l01.c` 通过 `extern uint8_t Channal`
引用它）：

```c
uint8_t Channal = 36;   /* 遥控器通道号，0~125 */
```

## 四、程序接口

遥控器相关程序位于：`remote_control.c`、`remote_control.h`、`nrf24l01.h`。

### 初始化

```c
remote_control_init();   /* 记得先设置通道号！ */
```

### 读取摇杆状态

```c
RcRockerKeyValueRead();  /* 返回左/右摇杆的 X/Y 值 */
```

### 读取按键状态

```c
RcKeyValueRead();        /* 返回各按键的按下状态 */
```

## 五、注意事项（重要）

- **`nrf24l01.c` 库里的中断处理函数不能改、不能注释**，请保留最初始的样子。
  该中断是无线收发时序的核心，任何修改都会导致通信失败。
- 初始化手柄前务必确认通道号，收发两端通道不一致时收不到任何数据。
