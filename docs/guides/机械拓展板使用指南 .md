# 机械拓展板使用指南

机械拓展板承担绝大部分 IO 输出（P60/P62/P64/P66/P74/P75/P76/P77），程序已由学长
学姐烧录好，使用时只需要在主控板上电前接好它。

## 安全须知

1. **板子插上电池、打开开关后即上电，严禁对任何接口进行插拔**。要拔电池，先关
   电源开关断电，再拔。
2. 安装舵机、激光管、摩擦轮时注意 3P 黑色排针的**丝印标识**，不要插错。
3. **拓展板程序已烧录好，千万不要给它烧录任何程序**。若程序被误擦除，联系学长
   学姐付费恢复（10 积分 / 次）。

## 丝印说明

| 丝印 | 含义 |
| --- | --- |
| `NC` | NO CONNECT，未连接，没有任何信号 |
| `P××` | 连接到主控芯片的引脚号，如 P60、P62 |

## PWM 分组限制（重要）

扩展板的 PWM 频率按组共享，不是每个引脚独立设置：

- PWMA：P60、P62、P64、P66 共用频率
- PWMB：P74、P75、P76、P77 共用频率

同组四路必须使用同一个初始化频率。50Hz 适合摩擦轮、舵机和抖动电机，10000Hz
适合平滑电机。工程可以自由选择两组频率；步兵 PWMA 固定为 50Hz、PWMB 固定为
10000Hz，平滑电机占用 PWMA 时允许生成但会提示 Warn，实机可能一卡一卡。

| 位置 | 引脚 | 可接外设 |
| --- | --- | --- |
| 左侧 | P77、P76、P75、P74 | 四路电机 / 四路舵机 |
| 板子中间 | P60、P62 | 两路电机 / 两路舵机 |
| 摩擦轮区 | P64、P66 | 两路摩擦轮 / 两路舵机；不用于轮电机或拨弹电机 |

## 主控板怎么用拓展板

主控板通过 UART 通信协议把指令发给拓展板，实现电机、舵机和摩擦轮的控制。
接口与命令详见 [RM电控指南](RM电控指南.md)。
