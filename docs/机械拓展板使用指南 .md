# 机械拓展板使用指南 

注意事项：

1\.板子插上电池，打开开关后，**即板子上电，不能对任何接口进行插拔**。若想拔掉电池，先关电源开关断电，再拔电池。

2\.安装舵机、激光管、摩擦轮时，注意3P的黑色排针不要插错，**关注丝印标识**。

3\.部分丝印意思：

NC：NO CONNECT，未连接，表示没有任何信号

P××：指连接到主控芯片的某个引脚号，如P60、P62

4\.**有部分外设的PWM信号是同一路，不能同时使用，**即当P××的引脚号一样时不能同时使用。例如，当使用Motor5电机时，便不能再使用第一路P60舵机。

①左侧四路电机与四路舵机，P77、P76、P75、P74

②板子中间两路电机与两路舵机，P60、P62

③两路摩擦轮与两路舵机，P64、P66
