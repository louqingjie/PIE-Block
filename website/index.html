PIE-Block 开发者预览版

参数填好，固件到手

PIE-Block 面向 W.PIE RoboMaster 校内赛，是运行在 Windows 上的分步式机器人配置与固件生成工具。

把引脚、通道、速度、动作拆成可以照做的步骤，确认后即生成可编译的 STC32G C 代码——内置离线工具链，免驱 USB-HID 一键烧录。

设计目标

PIE-Block 让第一次接触单片机的同学也能配出机器人

机器人代码的门槛往往不在控制逻辑，而在寄存器、引脚复用和那一串点不亮的初始化。

PIE-Block 把这些拆成可以照做的步骤：按硬件方案填参数，生成前先做静态校验，确认后交给内置工具链编译，再通过免驱 USB-HID 写进主控板。

分步向导

Step by step

按机器人结构分页配置，每个字段都标注单位与建议区间。填完就是一份能编译的工程，不需要先学会 C 语言。

静态校验

Static validation

引脚占用、按键冲突、取值范围、跨页一致性在生成前一次性检查完，每条问题都能点回它所在的字段。

内置离线工具链

Offline toolchain

SDCC C251 与固件模板随安装包发布，首次使用时释放到本地目录并校验版本与哈希，全程不联网。

工作流

从填参数到固件上板

四段流水线，每一段都能单独停下检查。

01

按步骤描述硬件

向导按机器人结构分页：遥控器与底盘、云台与拨弹、控制与摩擦轮。引脚分配、通道号、速度、按键用途都是带范围提示的字段，改几个参数就能适配另一套硬件方案。

  • 步兵 6 步、工程 7 步、调试 4 步、音乐 4 步
  • 字段带单位与建议区间，越界会即时提示
  • 工程文件自动保存，跨页共享的配置在摘要页统一复核
02

生成前先把问题拦下来

摘要页会把整份配置扫一遍：引脚是否被两个外设抢用、按键是否重复绑定、速度是否落在可用区间、摩擦轮占空比是否是 500–800 的整百值。

  • 错误清零后才允许生成代码
  • 警告给出具体的调参建议，而不是只报不合规
  • 每条问题点一下就跳回它所在的字段
03

生成可编译的 C 代码

前面填的每一项都会落到同一份 main.c 上：引脚与 PWM 角色、按键映射、速度区间按你的硬件方案展开，生成规则集中在一处，配置和代码一一对应。

  • 只读实时生成，带行号与 C 语法高亮，可搜索、可整段复制
  • 一键导出 main.c，直接拿进 Keil 或其它工程
  • 编译与烧录需要本机工具链与 USB-HID，在桌面版完成
04

音乐也能烧进去

音乐项目提供原生钢琴卷帘：选择、画笔、删除、平移四种工具，吸附精度从 1/4 一直到三连音与 1/32。导入 MIDI 会自动挑出旋律轨道并提取主旋律，写完在应用内试听，再生成 P33 无源蜂鸣器的单音固件。

  • MIDI 导入导出，重叠音自动提取为单音主旋律
  • 速度与拍号事件按 Tick 编排，支持循环预览
  • 参考音符只读，选中后可提升为主旋律
项目类型

四种项目，对应四类任务

新建项目时选一种，向导会按它的步骤链往下走。

步兵

6 步
遥控器与底盘 云台与拨弹 控制与摩擦轮 检查与摘要 生成代码 编译与烧录

四轮底盘、云台轴、拨弹电机与摩擦轮一页配完，PWM 与引脚角色由配置自动推导。

工程

7 步
遥控器与底盘 PWM 与引脚 模式切换 动作映射 检查与摘要 生成代码 编译与烧录

支持 1–4 组独立控制模式，可为每组模式单独编排动作映射与切换按键。

调试

4 步
测试序列 检查与摘要 生成代码 编译与烧录

固定的十路启停测试序列，按顺序验证电机与舵机接线，带默认 3 秒安全时长。

音乐

4 步
钢琴卷帘 检查与摘要 生成代码 编译与烧录

原生钢琴卷帘编排旋律，导入导出 MIDI，生成 P33 无源蜂鸣器的单音固件。

开始使用

下载安装包或从源码构建

下载安装包

Windows 10/11 x64。安装包已内置 SDCC C251 工具链与固件模板，装完就是完整开发环境，不需要另外配环境变量。

PIEBlock-1.1.0-windows-setup.exe
从 GitHub 下载 查看源码

从源码构建

获取完整源码，配置好 Flutter 环境后构建 Windows 桌面版；仓库内同时包含 SDCC C251 工具链的构建与暂存脚本。

$git clone https://github.com/louqingjie/PIE-Block.git
$flutter pub get && flutter build windows
需要 Flutter stable 与 Windows 桌面构建工具链
