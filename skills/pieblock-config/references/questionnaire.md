# 配置需求澄清清单

## 为什么先问

`.pieproj` 里的引脚、方向、通道、速度都是**实车相关**的。猜错的代价是轮子反转、电机堵转、
通道对不上，甚至上台架就撞。先把下面问题问清，再动参数；用户说不清的地方，给出默认值并
**明确标注为假设**，让他确认。

## 1. 工程与目标

| 问题 | 说明 |
| --- | --- |
| 新工程还是改现有工程？ | 新工程必须由用户在应用里新建并保存；改现有工程要先拿到 `.pieproj` 路径 |
| 工程类型是什么？ | 步兵 / 工程 / 调试 / 音乐。全向、麦轮混控、机械臂等自定义构型只能用「工程」 |
| 要保留现有配置吗？ | 改现有工程时，候选必须从**当前工程**复制，只改需要项；不要拿示例整份替换 |
| 有备份吗？ | 建议应用前把 `.pieproj` 复制一份（应用内撤销只有一步） |

## 2. 底盘（按构型）

| 问题 | 备选 |
| --- | --- |
| 底盘构型 | 差速四轮 / 四轮麦轮 / 三轮全向（120°）/ 四轮全向（90°）/ 其他 |
| 轮子数量与用途 | 3 或 4 个驱动轮；是否要原地旋转 |
| 驱动电机接哪些输出脚 | 常见 P74–P77（PWMB、10000 Hz）；P60/P62 也可作电机 |
| 同一组 PWM 的其余引脚打算做什么 | 舵机、摩擦轮、未使用 |
| 方向/符号怎么确认 | 台架单轮点动；用户确认「正转」对应车体哪个方向，AI 不假设 |
| 需要转向（自转）吗 | 需要时右摇杆 RX 作开环转向，增益 0.5 起调，注意极性 |

## 3. 遥控与按键

| 问题 | 默认（假设时使用） |
| --- | --- |
| 遥控器通道号 | 36（步兵/工程模板默认） |
| 摇杆死区 | 100 |
| 模式数量 | 1（多模式需要切换键与模式内按键布局） |
| 各模式切换方式 | 循环（`cycle`）或直选（`direct`），需要模式键 |
| 摩擦轮/拨弹/机械臂用哪些按键 | 按用户习惯；不要与模式切换键冲突 |

## 4. 速度与安全

| 问题 | 建议 |
| --- | --- |
| 普通速度 / 冲刺速度 | 首次台架 ≤3000；常规 4000–8000；不要默认 10000 |
| 是否启用冲刺 | 默认关闭，确认后再开 |
| 限幅/中位/方向 | 舵机需要中位与逆/顺时针限幅时，按实际机构给值 |
| 台架条件 | 轮子悬空、机械臂支撑、急停可用、低占空比起步 |

## 5. 默认值（用户说“你决定”时使用，必须标注为假设）

| 参数 | 默认 |
| --- | --- |
| 遥控通道 / 死区 | 36 / 100 |
| PWMB 频率 | 10000 Hz（P74–P77 平滑电机） |
| PWMA 频率 | 50 Hz（P60/P62/P64/P66 舵机/摩擦轮） |
| 四轮麦轮方向（预制底盘） | 左前/左后 `forward`，右前/右后 `reverse`（模板值，实车必须台架确认） |
| 轮速表达式缩放 | `*10000/2047`，转向增益 `0.5*RX` |
| 首次测试占空比 | 3000 以下 |
| 模式数 | 1 |

以上默认值只是起点，不是对硬件的保证。

## 6. 新工程怎么建

CLI 不能创建工程。请用户：

1. 打开 PIE-Block → 新建工程 → 选 **工程**（全向/麦轮混控/机械臂）或 **步兵**（必须用预制底盘）；
2. 保存到任意路径，把 `.pieproj` 路径发给你；
3. 你基于这个空工程生成候选并 `propose`。

## 7. 隐私与工程片段

- 只读取生成候选需要的字段；`.pieproj` 是纯参数，需要外部排查时可直接提供，**不需要脱敏**；
- 截图/日志里的本机路径、用户名等无关信息，自己看一眼再发即可。
