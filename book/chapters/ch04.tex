\chapter{云台、拨弹与摩擦轮}
\label{ch:gimbal}

\begin{introduction}
  \item 配置云台两个轴：驱动类型、IO、归中偏移与限位；
  \item 区分两种拨弹模式：阻塞开环单发与目视闭环连续拨弹；
  \item 理解摩擦轮的 0--100\% 油门比例与两侧满油占空比的映射律；
  \item 看懂固件里的摩擦轮安全栈：500 启动、1 秒激活、$\pm1$ duty 渐变；
  \item 为拨弹、摩擦轮、云台归中分配按键并完成校准。
\end{introduction}

底盘会走只是及格线，步兵真正的任务由“武器”完成：云台带瞄准机构指向
目标，拨弹电机把弹丸送进摩擦轮，摩擦轮把弹丸加速射出。本章把
“云台与拨弹”页和“控制与摩擦轮”页的每个字段填明白——这两页是步兵
向导的第 2、3 步。示例仍用随书的
\texttt{infantry-standard.pieproj}。

先记住硬件边界（详见附录~A）：主控板只有 MP03、MP74 两个舵机口，只能接
舵机；机械拓展板的 P60、P62 可作电机或舵机；P64、P66 是摩擦轮区，可作
摩擦轮或舵机，但不能当轮电机或拨弹电机用。同一端口在同一时刻不能既作
电机又作舵机。

\section{云台：两个轴的执行器}

\subsection{配置执行机构}

向导第 2 步“云台与拨弹”页如图~\ref{fig:ch04-mechanism} 所示。云台分
Yaw（偏航，水平旋转）与 Pitch（俯仰）两个轴，每个轴默认有一个执行器，
可以“添加执行器”扩成多电机（例如双电机驱动的 Yaw 轴，固件里会生成
\texttt{yawDuty} 与 \texttt{yawDuty2} 两路同步输出）。每个执行器要填
四项：

\begin{itemize}
  \item \textbf{驱动类型}：电机或舵机。舵机走主控板的 \texttt{PWM\_Init/
        PWM\_SET\_Duty}，电机走拓展板占空比帧；
  \item \textbf{IO}：随驱动类型联动——选舵机时下拉框只给出 MP03、MP74
        与设为 50\,Hz 的拓展板端口；选电机时只给出电机端口；
  \item \textbf{方向}：纠正安装方向，与底盘单轮方向同一套逻辑；
  \item \textbf{归中偏移}：舵机“机械正前方”对应的相对中位角度
        （$-90^\circ$ 到 $+90^\circ$）。舵盘装配时不可能恰好居中，把
        偏差填在这里，固件的归中位置就会落在机械正前方。
\end{itemize}

“最小限位”“最大限位”是该轴相对归中位置的左右/上下限位角（选填，
$-90^\circ$ 到 $+90^\circ$）。固件把可用行程钳位在“归中偏移 $\pm$ 限位”
与电气端点 250--1250 的交集上；未配置时限位即 $\pm90^\circ$，行程上限由
机械限位负责。同一轴有多个执行器时，各执行器的限位区间必须相交，否则
无法全轴钳位（校验器会报错）。

\subsection{右摇杆与云台归中}

云台由右摇杆控制：水平轴驱动 Yaw，垂直轴驱动 Pitch。对舵机执行器，摇杆
控制的是\textbf{转速}而不是绝对角度——满杆时每主循环转过约
$0.36^\circ$（约 $18^\circ$/s），轻推则慢动，松手即停。这对舵机云台是
最自然的操控方式，也避免了角度直接映射下摇杆死区带来的“对不准”。

对电机执行器，摇杆值直接按比例映射成占空比（满杆 10000），适合直流电机
直接驱动的云台。

按住 RC（右摇杆按下）让云台归中：两轴回到各自的归中位置。这个功能由
“控制与摩擦轮”页底部的“按下右摇杆让云台归中”开关打开，比赛里用于
快速回正视线。

\section{拨弹电机}

拨弹电机把弹丸从弹仓送进摩擦轮。步兵的四个轮电机占满了固定 10000\,Hz
的 PWMB 组，拨弹电机只能落在固定 50\,Hz 的 PWMA 组（P60/P62 二选一），
因此页面上会有一条“电机可能一卡一卡”的提醒——50\,Hz 下占空比每轮
变化的台阶较大，低速时可能显得不平滑。这是引脚拓扑决定的既定取舍：
拨弹只需要“送弹”这一个动作，对平滑度不敏感。

“拨弹模式”有两种：

\begin{itemize}
  \item \textbf{阻塞开环单发}：扳机键每按下一次，拨弹电机以设定的拨弹
        速度（0--10000 duty）转动一个“单发时长”（毫秒），把一颗弹丸送进
        摩擦轮。单发期间固件阻塞等待，底盘和云台暂时不更新——所以单发
        时长不宜填大，校验器对过长的时长会提醒“单发期间底盘和云台会失去
        响应”。250\,ms 是常用的起始值，装弹节奏按实弹微调；
  \item \textbf{目视闭环连续拨弹}：按住扳机键持续拨弹，松开即停，由操作手
        目视控制发射节奏，适合弹仓供弹顺畅的发射机构。
\end{itemize}

“反向拨弹键”（可留空）按住时按相反方向持续转动，用于卡弹时退弹——
比赛里卡弹的黄金处理就是“倒一下再打”。

\section{摩擦轮：油门比例与安全栈}

\subsection{为什么用 0--100\% 的油门}

摩擦轮是无刷电机 + 电调：电调只认 PWM 占空比，且对启停方式有硬性要求
（《RM 电控指南》原文：违反可能烧毁电机或拓展板，需照价赔偿）。直接让
使用者填占空比有两个问题：一是占空比与转速的对应关系因电机而异；二是
安全规程（500 启动、逐步提速、上限红线）很容易被填错。

PIE-Block 的做法是把\textbf{油门百分比}（0--100）作为唯一控制量，把安全
规程固化在固件里。两个摩擦轮分别配置一个\textbf{满油占空比}（500--800
的整百值），用来补偿两侧机械差异导致的转速差：

\begin{equation}
  \operatorname{duty}(\text{引脚}) = 500 + \frac{\text{油门}\% \times
  (\text{该引脚满油上限} - 500)}{100}.
  \label{eq:ch04-friction-map}
\end{equation}

例如 P64 上限 700、P66 上限 800 时，油门 0\% 得 $500/500$，50\% 得
$600/650$，100\% 得 $700/800$。500 是电调启动信号，固定不可调，同时作为
映射下界；用户可配的上限本身就在 1100（11\%）红线以内。

\subsection{按键与油门步长}

摩擦轮需要三个按键（见图~\ref{fig:ch04-controls}）：\textbf{开关键}在
0 与当前油门档位之间切换；\textbf{增速键}与\textbf{减速键}每次按
“每次油门步长”（1--100\%）加减油门。两侧目标占空比每个主循环由油门按
式~\eqref{eq:ch04-friction-map} 重新映射，两侧各自逼近自己的目标。

\subsection{固件里的安全栈}

不管油门怎么变，摩擦轮的占空比都要走同一条“安全栈”：

\begin{enumerate}
  \item \textbf{启动激活}：从静止启动时，先输出 500 启动占空比并保持
        1000\,ms 完成电调激活（步兵固件按主循环整圈折算，实际不短于
        1000\,ms），激活期间蜂鸣器不发声；
  \item \textbf{平滑渐变}：激活后两侧各自以每周期 $\pm1$ duty 逼近目标。
        主循环约 20\,ms 一圈，变化率约 50 duty/s，是《RM 电控指南》
        “每秒最多增加 100”上限的一半。渐变必须作用在占空比上——若作用
        在油门上，800 上限的一侧每步会跳 3 duty，约 150 duty/s，越界；
  \item \textbf{无效区间}：电机在 5\% 占空比以下不转，输出只取 0 或
        500~各自上限，启停时跳过 $0\sim500$ 区间；
  \item \textbf{停机斜坡}：关闭时沿同一条斜坡逐档降回 500 再跳到 0，
        不得高速直接断电；开关键按下即把油门置 0。
\end{enumerate}

生成代码里这一整套逻辑对应一组常量与一个映射函数，摘录如下：

\begin{lstlisting}[style=pieblockc,
  caption={步兵固件的摩擦轮常量与映射函数（随书示例生成代码节选）},
  label={lst:ch04-friction}]
#define FRICTION_START_DUTY 500
#define FRICTION_STEP_DUTY 1
#define FRICTION_LEVEL_MAX 100
#define FRICTION_MAX_DUTY_P64 700
#define FRICTION_MAX_DUTY_P66 800
#define FRICTION_LEVEL_STEP 10
#define FRICTION_LOOP_MS 20
#define FRICTION_ACTIVATE_MS 1000

static uint16_t FrictionDutyOfLevel(uint8_t level, uint16_t maxDuty) {
    return (uint16_t)(FRICTION_START_DUTY
        + ((uint16_t)level * (uint16_t)(maxDuty - FRICTION_START_DUTY)) / FRICTION_LEVEL_MAX);
}
\end{lstlisting}

\begin{note}
摩擦轮类型选择“无刷电调”后会\textbf{固定占用 P64/P66}：若这两个端口
已被别的设备使用，页面会列出占用者并要求确认“关闭摩擦轮并占用”或
“交换引脚”。选择“不使用”时两个端口释放。旧式控制方式（普通“电机”
角色直接写占空比）写在摩擦轮脚上仍可生成，但没有安全斜坡保护，页面会
提示“不受安全斜坡保护”；同一配置里不能与新摩擦轮方式混用。
\end{note}

\subsection{满油占空比怎么定}

满油占空比是摩擦轮唯一需要标定的参数，按下面的流程做：

\begin{enumerate}
  \item 先把两侧上限都填 800（或按已有经验值），油门步长 10\%；
  \item 架空发射机构，人员离开射界，按开关键启动：电调激活后摩擦轮应
        以 500 duty 空转——若连 500 都带不动（低于 650 的目标占空比
        校验器也会提醒），说明机械阻力过大或电调油门行程需要重新学习；
  \item 按 B 键逐档加油门，听两侧电机声音、看弹丸初速是否一致；两侧
        转速差明显时，把偏慢一侧的上限调高（或偏快一侧调低）；
  \item 定稿后把常用交战距离的弹道记下来，比赛时只动油门档位，不再动
        上限。
\end{enumerate}

\section{按键分配与高级设置}

“控制与摩擦轮”页的上半部分是拨弹的按键：扳机键（示例用 E）、反向拨弹键
（D）、方向键用途和拨弹参数。所有按键在同一步内完成冲突检查：同一个数字
按键不能分配给两个动作；方向键用作拨弹或摩擦轮时不能再当“移动”用；
LC 已被底盘冲刺占用、RC 已被云台归中占用，都不能重复分配——冲突会在
检查页以错误列出，并可以点击跳回本页修改。

“高级设置”里有一个开关：“禁用蜂鸣器反馈”。步兵固件在上电自检和运行
状态变化时会用主控板 P33 的蜂鸣器给出提示音（启动诊断是一段上行琶音）；
安静的调试环境或夜间调试时可以整体关掉。蜂鸣器真正的用法在
第~\ref{ch:music}~章——音乐项目会把 P33 变成一只可以演奏曲谱的喇叭。

\section{本章小结}

\begin{itemize}
  \item 云台两轴各配执行器：舵机填归中偏移与限位，电机直接映射占空比；
        右摇杆控制转速，RC 归中；
  \item 拨弹电机在 PWMA（50\,Hz），阻塞开环单发适合固定供弹，目视闭环
        适合连续发射；反向拨弹键用来退卡弹；
  \item 摩擦轮以油门百分比为唯一控制量，两侧满油占空比按
        式~\eqref{eq:ch04-friction-map} 映射，安全栈固化在固件里；
  \item 按键冲突在配置期就会被查出来，不需要等实车才发现。
\end{itemize}
