\section{PIE-Block 简介}

PIE-Block 是面向首都师范大学 RoboMaster 校内赛的机器人图形化配置集成开发环境，运行于
Windows 与 Linux 桌面端。它把「让机器人按预期动作」拆成一组可以照做的步骤：在向导中
选择项目类型，填写遥控器通道、底盘、云台、拨弹与摩擦轮参数，安排按键功能；随后由程序
检查配置是否自洽，生成 STC32G 的 C 代码，调用内置的 SDCC C251 工具链完成编译，再通过
免驱 USB-HID 把固件写入主控板。整套流程不需要使用者自行搭建编译环境，也不需要手写
寄存器操作代码。

在 PIE-Block 出现之前，完成同样的事情往往要跨过几道门槛：读懂 STC32G 的引脚与定时器
手册，弄清每个电机、舵机接在哪一路 PWM 上，配置 Keil 或 SDCC 的工程与链接参数，再处理
烧录工具和驱动。任何一处引脚或参数写错，现象可能只是「机器人不动」或「一上电就抖」，
排查成本很高。PIE-Block 把这些隐性知识固化进向导与检查器：PWM 与引脚角色按硬件拓扑
自动推导，字段范围、引脚占用、按键冲突和跨模式一致性在生成代码之前就被指出，构建结果
按内容哈希复用，烧录前还会核对 HEX 的地址与校验和。

正因为它把「写代码」变成了「填参数、看检查结果」，本书的读者并不限于有编程经验的人。
本书主要面向两类读者。

\begin{itemize}
  \item \textbf{参加首都师范大学 RoboMaster 校内赛的机械组成员。}
        这类读者通常负责结构设计、装配与整车联调，未必系统学过 C 语言和单片机。
        通过本书，可以掌握：按硬件方案完成步兵、工程、调试等项目的配置；理解 PWM、
        引脚角色与摩擦轮油门比例等参数的含义；独立完成代码生成、编译与烧录；在赛场上
        快速定位配置类故障。

  \item \textbf{研究 STC32G 编译、汇编和烧录的开发者。}
        这类读者关心的是工具链与产物本身：生成的 C 代码如何组织，SDCC C251 怎样把 C
        编译成 251 指令，链接后的 \texttt{main.rst} 列表文件如何把地址、机器码、汇编与
        C 源码对应起来，HEX 的格式与校验如何检查，USB-HID 烧录怎样分块写入。PIE-Block
        把这些环节都暴露在界面里，既可以作为研究 STC32G 开发流程的入口，也可以作为
        二次开发的基础。
\end{itemize}

两类读者的阅读路径不同。机械组成员可以从第~\ref{ch:quickstart}~章开始，先跟着做一遍
完整的步兵机器人项目，再按需查阅第~\ref{ch:chassis}~至第~\ref{ch:music}~章中与自身
分工相关的内容；开发者可以先读第~\ref{ch:codegen}~章「代码生成与静态检查」和第%
~\ref{ch:flash}~章「编译、烧录与联机调试」，建立对产物与工具链的整体认识，再回到前面的
章节理解配置是如何一步步变成代码的。第~\ref{ch:advanced}~章与三个附录则集中收录项目
文件格式、常见故障与速查表，供两类读者在遇到问题时查阅。
