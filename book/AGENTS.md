# PIE-Block 教材（book/）写作规范

本文件约束 `book/` 目录下的全部内容：`chapters/*.tex` 正文、图注、表格、示例说明、
`README.md` 以及新增章节。目标是让全书保持统一的**正式教材语体**，可直接印刷与
课堂使用。

## 一、语体总则

1. **正式、客观、书面语**。以陈述事实与解释机理为主，不用口语、网络语、流行语、
   语气词（"其实""说白了""一口气""搞定""贼快"等一律不用）。
2. **不使用第二人称**。"你""您""咱们""你的车"等一律改为无人称表述或"读者"。
   教材描述的是操作与装置，不是与某个人对话。
3. **不使用口语化比喻**。比喻只在术语解释确有帮助时使用，且必须紧随一句严谨定义。
4. **术语优先于修辞**。能用术语说清楚的，不用形容性描述代替。
5. **一段一个判断**。段落以结论句开头或结尾，避免流水账式叙述。

## 二、术语与符号

- 术语以 `chapters/appendix-c.tex`（术语表）为准，全书不得出现同物异名。
  例如：`摇杆`、`方向键`、`单轮方向`、`占空比`、`通道号`、`死区`、`扩展板`。
- 英文缩写首次出现时写全称并附缩写，如"机械拓展板（下称扩展板）"。
- 代码标识符统一用 `\texttt{}`，变量名保持代码原样，不改写大小写。
- 数值与单位遵循 GB 3100–3102：数字与单位间用细空格 `\,`，如 `10000\,Hz`。
- 交叉引用一律用 `\ref{}` / `\eqref{}`，不手写"图 3.1""上式"。

## 三、禁止的口语化写法（附改写示例）

| 不推荐（口语） | 推荐（教材语体） |
| --- | --- |
| 这轮应该往前转 | 该轮按车体前进方向转动 |
| 方向键是"摇杆的替身" | 方向键可替代左摇杆输出前后与转向分量 |
| 这是比赛里最顺手的冲刺方式：拇指不用离开摇杆 | 该按键位置便于在推杆过程中同时触发冲刺 |
| 手感不对再调 | 若操控响应不理想，再调整死区取值 |
| 摇杆不顺手时…… | 摇杆操作不便时…… |
| 应用不会替你预选 | 应用不会自动预选 |
| 看看 PIE-Block 替你查了什么 | 说明 PIE-Block 在生成前执行了哪些检查 |
| 如果某个轮子的符号和你…… | 若某轮的输出符号与预期相反…… |

同类应避免的表述还包括：`咱们`、`说白了`、`其实`、`搞成/搞定`、`一口气`、
`照着抄`、`拍脑袋`、`闭着眼睛`、`很爽`、`贼`、`一下`（作虚词时）、
`这个东西/那个东西`（指代具体部件时应写其名称）。

## 四、标点与排版

- 中文引号统一使用弯引号 “ ”，不使用「」或直角引号。
- 中文正文使用全角标点；英文单词、代码、公式与中文之间不加空格。
- 冒号后接解释、破折号用“——”，不用连续三个短横。
- 图注、表注为完整句子或名词短语，不加句末句号（与现有风格一致）。
- 列表项以分号结尾、末项以句号结尾。

## 五、结构与内容要求

1. 每章以 `introduction` 环境给出“内容提要”，条目为动宾短语（如“会用……
   页”“看懂……”），每条一行内写完，避免溢出窄栏。
2. 每章末尾给出小结或检查清单；清单项必须是可直接执行的检查动作。
3. 操作步骤按“前提 → 操作 → 预期结果”三步组织，明确写出可观察到的现象
   （如“四个轮子同时向前滚动”“屏幕显示通道号”）。
4. 涉及实机的内容必须写安全前提（架空、限速、标定），不省略。
5. 图片必须有 `\caption` 与 `\label`，图注说明图中各部件与缩写含义。

## 六、提交前自检

1. 通读改动段落，逐条核对上表禁用表述。
2. 全文检索：`你`、`咱们`、`替`、`其实`、`说白了`、`搞`、`顺手`、`手感`、
   `这东西`，确认无残留。
3. 在 `book/` 下执行 `latexmk -xelatex main.tex`，要求：
   - 编译无错误；
   - `main.log` 无新增 `Overfull \hbox`；
   - 无 `Missing character` 警告；
   - 新增 `\ref` 的引用均已解析。
4. 提交信息使用中文 Conventional Commits，例如
   `docs(book): 统一第三章表述为教材语体`。
